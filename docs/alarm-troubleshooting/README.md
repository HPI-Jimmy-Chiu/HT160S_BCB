# HT160S 警報／警示 檢修對應手冊

本資料夾提供 HT160S 全機 **576 則**警報／警示的檢修對應手冊，**寫給線上操作員（Operator）**，
目的是遇到異常時能**快速排除**。主軸是「**每個異常 = 某裝置未達預期狀態**」，逐則列出要檢查的
IO／汽缸／馬達／真空點的 **應該狀態（健康）→ 目前狀態（故障）**，以及在機台前的處置步驟。

## 檔案

| 檔案 | 用途 |
|---|---|
| [`HT160S_Alarm_Troubleshooting.html`](HT160S_Alarm_Troubleshooting.html) | 互動版（鴻勁紅配色、可搜尋代碼／關鍵字、淺深色切換）。用瀏覽器開啟，現場首選。 |
| [`HT160S_Alarm_Troubleshooting.md`](HT160S_Alarm_Troubleshooting.md) | Markdown 版（可在 GitHub / VS Code 檢視、可貼進其他文件）。 |
| `data/`（內部參考資料） | 汽缸／馬達代碼對照與各警報判讀的原始整理資料（`cyl_ref`／`mot_ref`／`op_out.json` 等），供日後**重建對照表**用，非操作員閱讀。 |

## 涵蓋範圍

| 代碼族 | 數量 | 說明 |
|---|---|---|
| 汽缸 `4xxxx` | 55 × 6 = 330 | 到位逾時（`…3` 伸出失敗 / `…0` 縮回失敗為現行實際觸發碼） |
| 馬達 `5xxxx` | 20 × 9 = 180 | 伺服電源／扭力／CW-CCW 硬限／軟限／位置誤差 等 |
| 真空 `6000x` | 1 × 6 = 6 | 分類手臂吸嘴組 `SortArmSuck` |
| 流程 `JAM/MES/WAR` | 60 | 盤流／視覺／計數；Auto1~6 六站同模式 |

## 重要判讀提醒（給操作員）

- 手冊只給**裝置名稱**（不列位址）；現場一律以**名稱**在 IOsetview 搜尋（例 `SnColor_InputHasTray`）。
- 感測器有**常開／常閉**之分，「亮／不亮」代表的意義可能相反；判讀不確定時一併告知工程師。
- 部分汽缸的到位感測器為**停用／未安裝**（例如 TrayArm 系列無縮回感測器、分離爪系列無到位感測器）；
  這些方向靠時間判斷、不發到位警報，找不到該感測器是正常的（對照表「說明」欄已標示）。
- 標**邏輯／計數**的項目沒有單一感測器可看，通常需要工程師協助。

## 資料來源

- **汽缸／馬達位址對照**：由機台開機時自動匯出的 `system/AlarmList.csv` 與 `system/IO_Table.csv`
  以 **Alias 名稱**交叉比對整理，為機台實際載入值。
- **流程碼判讀**：對照機台各模組實際運行行為整理而成。
- 生成日期：2026-07-13。

## 重新產生

`AlarmList.csv` / `IO_Table.csv` 變動後，可重建汽缸／馬達對照表（比對 代碼↔sensor↔位址）；
`.html` 由 `.md` 透過產生器重出，改 `.md` 後請一併重新產生 `.html` 以保持同步。
