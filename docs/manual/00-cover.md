## 文件慣例

- **語言**：內文使用繁體中文；畫面控制項名稱、按鈕標籤、參數識別字、軸名、訊號名一律保留原文（英文/識別字）以對應實機畫面。
- **適用對象分級**：操作員（OP）版手冊以「日常操作」為範圍——開機/關機、面板、主畫面、Lot 操作、警報排除、換線設定。Teach / Offset / Motor Test / IO 監看 / Maintenance 等工程畫面屬設備工程師權限，OP 僅需辨識、不得操作；相關章節於工程版保留，供 OP 版裁剪時剔除。
- **待補標記**：凡無法由原始碼確定、需現場驗證的內容，以 `> 【待補：說明】` 標註。請於實機校對時補齊。
- **截圖**：26 張截圖已置於 `screenshots/`，由 `scripts/ops/capture-ht160s-screens.ps1` 自模擬程式擷取，畫面與實機 UI 相同，直接引用。未涵蓋之畫面保留圖片版位與「擷取方式」說明，請手動補拍。
- **安全**：操作前務必詳閱「第 01 章 安全須知」。本機含伺服馬達與氣壓致動器，即使在 DUMMY 模式下馬達/氣缸仍會實際動作。
