# 第 10 章　輸出入監看 (I/O)

輸出入監看畫面（`fiosetview`，標題列 "IO check and verify"）讓維修人員即時觀察機台上所有輸入（感測器、汽缸到位、真空到位）與輸出（電磁閥 Switch、汽缸、吸嘴真空 V／破真空 D）的現況，並以 LED 與按鈕面板的顏色表示 ON／OFF。除監看外，本畫面亦可：

- 手動強制切換單一輸出；
- 對整組吸嘴執行 Suck（全部吸）／Destroy（全部破）／All Off（全關）；
- 線上編修 `IO_Table.csv`（Add／Delete／Modify／Save）；
- 匯出輸入／輸出位址對照表（IOMap）；
- 查看 MN200 MotionNet 介面卡的連線狀態。

離開畫面時，系統會依現場是否有料件，決定是否還原被動過的輸出，避免維修後在機台上留下危險的輸出狀態。

## 10.1 安全須知

> ⚠️ 注意：本畫面可在運轉外手動激磁輸出（電磁閥、汽缸、吸嘴真空）。在機台上料件仍在機內時強制輸出，可能造成機構碰撞、料件損壞或人員夾傷。手動操作前務必確認動作路徑淨空。

> ⚠️ 注意：機台運轉中（`SystemStart`）時，`UpdateLegacyPageTabsVisible` 會隱藏所有分頁標籤，避免運轉期間誤切到各 IO 頁觸動輸出。請勿在運轉中試圖手動切換輸出。

> ⚠️ 注意：離開畫面時若期間動過任何輸出（`bOutDataChange=true`）：機台內有料件（`HasICUnderMachine()`）→ 系統強制還原輸出，無選擇餘地；機台空 → 詢問操作員是否還原。原則：有料件在機內，絕不留下被動過的輸出狀態。

## 10.2 LED 與按鈕的顏色約定

顏色是判讀本畫面的核心，為硬性約定：

| 元件 | 顏色 | 意義 |
| --- | --- | --- |
| 輸入 LED（TMyLed） | 綠（clLime） | 該輸入 ON |
| 輸入 LED（TMyLed） | 灰（clSilver） | 該輸入 OFF |
| 輸入 LED（TMyLed） | 紅（clRed） | 該點未綁定，或 `Enable=0`（停用） |
| 輸出按鈕（TBtnPanel） | 亮橘（IO_COLOR_BUTTON_ON，16744448） | 該輸出 ON |
| 輸出按鈕（TBtnPanel） | 深藍灰（IO_COLOR_BUTTON_OFF，8404992） | 該輸出 OFF |
| 輸出按鈕（TBtnPanel） | 紅（clRed） | 該點未綁定，或 `Enable=0`（停用） |

> ⚠️ 注意：紅色一律代表「該 IO 點不可用」——可能是 `IO_Table` 沒有對應的 Alias、位址綁定失敗，或該點 `Enable=0`。紅色點無法手動切換。發現應作用的點顯示紅色時，請檢查 `IO_Table` 設定。

LED／按鈕的狀態由 `RefreshLegacyIOControls` 依各元件的 Alias 解析：可解析時依目前狀態上綠／灰（輸入）或亮橘／深藍灰（輸出）；無法綁定或停用時整顆顯示紅色。畫面在 `FormShow` 後啟用 `Timer1` 週期自動重新整理。

## 10.4 操作程序

### 10.4.1 監看輸入／輸出狀態

1. 由 Maintenance 或 Teach 進入輸出入監看畫面。
2. 點選 `PageIO` 上要觀察的模組分頁（Loader／Unloader／Sucker／Panel／System…）。
3. 判讀：綠燈＝該輸入 ON、灰燈＝OFF、紅燈＝該點未綁定或被停用（`Enable=0`）。
4. 畫面每隔 `Timer1` 週期自動重新整理（`FormShow` 啟用 `Timer1`）。

> ⚠️ 注意：機台運轉中（`SystemStart`）分頁標籤會被隱藏，避免運轉時切頁誤操作。

### 10.4.2 手動強制切換單一輸出

1. 切到對應模組分頁。
2. 點該輸出按鈕（`TBtnPanel`），Toggle 切換 ON／OFF。
3. Switch／Cylinder 為單純反相切換；吸嘴 V（真空）與 D（破真空）互鎖——開其一會自動關另一（9045 風格：On＝破真空關＋真空開、Off＝真空關＋破真空開）。
4. 若按鈕未綁定或該輸出停用，會彈出 `Output is not bound or disabled.` 並記錄 `LogManualOutputAction(..., UNBOUND_OR_DISABLED)`。
5. 任一次成功切換會設定 `bOutDataChange=true`，供離開時還原判斷。

> ⚠️ 注意：`BtnPanelClick` 已移除舊的手動輸出總開關（`IsManualOutputEnabled`），改為直接切換；僅由 `ToggleLegacyButtonOutput` 內部拒絕未綁定／停用點。每次動作以 `LogManualOutputAction` 記錄。

### 10.4.3 整組吸嘴 吸／破／全關

1. 切到 Sucker 分頁。
2. 選擇動作：
   - Suck＝全部真空（僅啟用之吸嘴）；
   - Destroy＝全部破真空（僅啟用）；
   - All Off＝強制全部關（不分啟用與否）。
3. 動作後系統設 `bOutDataChange=true` 並記錄 SuckerGroup 動作。

### 10.4.4 離開畫面與輸出還原

1. 點 Exit 或關閉視窗。
2. 若期間動過輸出（`bOutDataChange=true`）且非由 Teach 進入（`bFromTeach=false`）：
   - 機台內有料件（`HasICUnderMachine()`）→ 強制還原（`ShowMyMessage` 提示後 `RestoreOutputData`）；
   - 機台空 → 詢問操作員是否還原（Yes／No）。
3. 由 Teach 進入時（`bFromTeach=true`）不提示、不還原（維持 HT172 Teach 自由探測行為）。

> ⚠️ 注意：`FormShow` 進入時系統已先 `BackupOutputData` 備份所有 Switch／Cylinder／Sucker 輸出，作為離開時還原的依據。安全原則：有料件在機內絕不留下被動過的輸出。

### 10.4.5 線上編修 IO_Table

1. 切到 IODatabase 分頁（或用 Tool 的 Input／Output／Vacuum／Cylinder 快速篩選）。
2. 以 `cbbType`／`cbbLane`／`edtSearchIO` 縮小範圍。
3. 編輯：Add 新增列、選格後 Modify（或雙擊）以 InputBox 修改、Delete 刪列。
4. 點 Save（`sbUpdate`）：先 `ValidateIOTableGrid` 驗證 → `BackupIOTableFile` 備份原檔 → 寫回 `IO_Table.csv` → `LoadIoData` 並重新繫結 Sensor／Cylinder／Switch／Sucker 物件 → 重載與重繪。
5. 存檔成功會顯示備份路徑；失敗顯示錯誤。

> ⚠️ 注意：存檔前必先驗證且備份原檔（備份失敗即中止存檔）。備份保留上限由 `PruneIOTableBackups` 控管。儲存後免重啟即生效（因額外呼叫 `LoadXxxParameterFromDataBase` 重新繫結 IP／Port／Bit）。

### 10.4.6 查看 MN200 介面卡狀態

1. 切到 MN200 分頁。
2. `lblMN200Summary` 顯示開卡狀態／ring 數／MotionNet 點數，或錯誤訊息。
3. `grdMN200` 每列顯示各 ring 的 Started／Devices／ErrorCode。

> 模擬版（`SOFT_SIMULATE`）不開卡，改顯示模擬模式提示。

## 10.5 MN200／IO 位址模型

本機 IO 點以 `IO_Table.csv` 定義，每筆透過 `TMyIo` 組合出實際位址。對 MN200 MotionNet 介面卡而言，`Lane` 即環（ring）編號：

- 卡號 `iCard = iLane × 100 + iIP`；
- 位址要素：`iLane`（ring）、`iIP`、`iPort`、`iBit`、`ISABase = iISABase`；
- 感測器顯示值 = `(iInType==1) ? RawOn : !RawOn`（極性換算）；
- `MN200_MAX_RING = 8`；MN200 頁僅統計 `iISABase == eMotionNet` 且 `iEnable != 0` 的點數。

### IO_Table.csv 欄位（TIODATA）

每筆 IO 點定義一個感測器或輸出。表頭：`IOType,Alias,Lane,ModuleType,IP,Port,Bit,InType,ISABase,Enable,OnAlarmTime,OffAlarmTime,OnDelayTime,OffDelayTime,Note`，存於 `HSys.IoTablePath` 指向之 `IO_Table.csv`。

| 參數 | 範圍／預設 | 說明 |
| --- | --- | --- |
| Type（IOType） | SENSOR／SUCKER／SWITCH／CYLINDER／CYLINDER_ON／_OFF／SUCKER_ON／_OFF | IO 點型別 |
| Alias | 字串 | 點名稱，畫面 LED／按鈕依此綁定 |
| Lane（iLane） | 環／卡編號（ring） | MN200 即 ring 編號 |
| ModuleType（iModuleType） | — | 模組別 |
| IP（iIP） | — | 位址 IP 要素 |
| Port（iPort） | — | 位址 Port 要素 |
| Bit（iBit） | — | 位址 Bit 要素 |
| InType（iInType） | 通常 0／1 | 感測器極性；1＝直接採用原始位元（RawOn），其他值＝反相（!RawOn） |
| ISA Base（iISABase） | 0..4 | 介面類別（見下表 eIOType） |
| Enable（iEnable） | 0／1 | 0＝停用 → LED／按鈕顯示紅色且不可手動切換 |
| OnAlarmTime／OffAlarmTime | — | 到位／離位逾時告警時間 |
| OnDelayTime／OffDelayTime | — | 到位／離位延遲時間 |
| Note | 字串 | 備註；`COMM_PAD` 代表 Pad 通訊點 |

### ISA Base / eIOType（介面類別）

| 值 | 識別字 | 說明 |
| --- | --- | --- |
| 0 | eMotionNet | MN200 MotionNet |
| 1 | eISABase | ISA 介面 |
| 2 | ePCI1735U | PCI-1735U |
| 3 | ePCI1203 | PCI-1203 |
| 4 | e_PLCbase | PLC |

### 顏色／篩選常數

| 參數 | 範圍／預設 | 說明 |
| --- | --- | --- |
| IO_COLOR_BUTTON_ON | 16744448（亮橘） | 輸出按鈕 ON 色 |
| IO_COLOR_BUTTON_OFF | 8404992（深藍灰） | 輸出按鈕 OFF 色 |
| IO_COLOR_GRID_FIXED | 9534289 | IO 表固定列底色 |
| LED 顏色 | clLime／clSilver／clRed | 綠＝ON、灰＝OFF、紅＝未綁定／停用 |
| cbbType 篩選索引 | 0=All,1=Sensor,2=Sucker,3=Switch,4=Cylinder | 以 Type 子字串比對；Tool 的 Input=1／Vacuum=2／Output=3／Cylinder=4 快速設定 |

## 10.6 互鎖與保護機制

> ⚠️ 注意：以下為本畫面的硬性互鎖，維修時不可繞過。

1. **顏色硬性約定**：綠＝輸入 ON、灰＝輸入 OFF、紅＝該點未綁定或 `Enable=0`；輸出按鈕亮橘＝ON、深藍灰＝OFF、紅＝未綁定／停用。紅色即代表 IO 點不可用或設定缺失。
2. **運轉中保護**：`SystemStart` 時 `UpdateLegacyPageTabsVisible` 隱藏所有分頁標籤，避免運轉中切到各 IO 頁誤觸輸出。
3. **吸嘴真空／破真空互鎖**（每個吸嘴）：On()＝破真空關＋真空開、Off()＝真空關＋破真空開，兩者不可能同時被激磁（9045 風格）。
4. **離開還原安全鏈**：動過輸出且機內有料件（`HasICUnderMachine`）→ 強制還原備份輸出（無選擇）；機內空 → 詢問；由 Teach 進入 → 完全不還原。
5. **手動切換僅作用於 Enable 的點**：`ToggleLegacyButtonOutput` 對 Switch／Cylinder／Sucker 皆檢查對應 Enable，停用點拒絕切換並提示 `Output is not bound or disabled.`。
6. **IO_Table 存檔保護**：存檔前先 `ValidateIOTableGrid` 驗證且 `BackupIOTableFile` 備份原檔，備份失敗則中止存檔。

## 10.7 訊息與告警

| 訊息 | 意義 | 處理 |
| --- | --- | --- |
| `Output is not bound or disabled.` | 手動點輸出按鈕但該 Alias 找不到對應 Switch／Cylinder／Sucker，或對應點 `Enable=0`（停用） | 以 `ShowMyOKMessageNoStop` 顯示；檢查 `IO_Table` 中該點 Alias／Enable／位址設定；同時記錄 `LogManualOutputAction(..., UNBOUND_OR_DISABLED)` |
| `IO table data invalid:` | Save 時 `ValidateIOTableGrid` 驗證未過（格式／重複 Alias／數值錯誤等），逐列列出錯誤（最多 20 列） | 修正表格內容後重新 Save；此訊息為 NoStop 不中止機台 |
| `IO_Table.csv backup failed. Save aborted.` | 存檔前備份原始 `IO_Table.csv` 失敗，為安全起見中止存檔 | 檢查備份目錄權限／磁碟空間後重試 |
| `IO_Table.csv save failed.` | 寫回 `IO_Table.csv` 過程發生例外 | 檢查檔案是否被佔用／路徑後重試 |
| `IO_Table.csv saved. (Backup: ...)` | 存檔成功提示（含備份路徑） | 資訊性提示，無需處理 |
| `IO already change, will restore IO!!` | 離開時偵測到動過輸出，且機內有料件 → 強制還原 | 系統自動 `RestoreOutputData` |
| `IO already change, want to restore?` | 離開時偵測到動過輸出，機內空 → 詢問是否還原（Yes／No） | 選 Yes 還原、No 保留現狀 |
