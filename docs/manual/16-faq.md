# 第 16 章　常見問題 (FAQ)

本章彙整 HT160S 操作員與維護人員最常遇到的問題，採問答 (Q/A) 形式呈現。所有答覆均依據程式原始碼萃取之規格撰寫；凡規格未完整支持之處，已採保守措辭並標註「待現場確認」。實際操作仍以實機行為與「第 01 章 安全須知」為準。

> ⚠️ 注意：本機含伺服馬達與氣壓致動器，即使在 DUMMY 模式下馬達與氣缸仍會實際動作。排除故障時務必確認機台已停止且人員手部離開動作行程。

---

## 16.1 開機、登入與啟動

### Q1. 開機後到可以生產，正常的操作順序是什麼？

正常的可見操作順序如下：

1. 程式啟動後開始背景初始化，主畫面狀態列顯示 `INIT`。
2. 在主畫面右上的 **User** 權限下拉選擇使用者權限（見 Q4）。
3. 視需要在 **Real / Dummy** 模式切換框切換 Real / HasTray / Dummy、在 **Start Mode** 切換框切換 Initial / Continue（兩者僅能在機台未啟動時切換）。
4. 按 **Home** 回原點，確認 `Confirm home?` 後等待 HOME 監控畫面顯示 `Home finished.`。
5. 在 **Lot No.** 輸入框輸入 Lot 編號。
6. 按 **Start** 啟動生產。

### Q2. 為什麼一開機馬達就上電了？這正常嗎？

是正常的。若操作面板（Pad）尚未與軟體通訊，軟體啟動時會自動把馬達電源接通（此時無互鎖）。當操作面板開始通訊後，馬達電源即改由前／後面板的 Power On／Off 鍵控制。

### Q3. 我按了 `Start` 但機台先去回原點，沒有馬上生產，是故障嗎？

不是。若機台尚未回原點，按 **Start** 會先自動進入回原點並顯示 HOME 監控畫面；回原點完成後會「自動續跑生產」，不會停機。這與直接按 **Home**（完成後停機）不同。

### Q4. 切換 Supervisor/Engineer 權限時要求輸入帳號密碼？

是。正式機切換到非 Operation 等級時，會依序跳出 **Login User ID** / **Login Password** 輸入框，帳號驗證成功才切換；輸錯會顯示「User ID or password is incorrect.」並還原為原等級。選 Operation 則直接降權、免密碼。

> 註（定案）：權限等級為 Operation(0) < Supervisor(1) < Engineer(2) < Honprec(3)（`UserRoleManager`）。目前**唯一的權限 gate**是 Maintenance 帳號管理頁需 Engineer 以上才能編輯；其餘畫面（Teach/Offset/Speed/Maintenance 等）開啟不檢查角色——工程畫面的管制以廠內規範為主。正式機開機預設 Operation。

### Q5. 按 `Start` 後跳出「Please Enter LotID !」怎麼辦？

按 **Start** 前 Lot 編號不可為空。請在 **Lot No.** 輸入框輸入 Lot 編號後重按 **Start**。

### Q6. 按 `Start` 後提示缺 Lot／2D 資料或「By Lot+Bin no binding」？

按 **Start** 前，系統會檢查 Lot 編號、Lot 筆數、2D／Bin 資料（以及 By Lot+Bin 模式的綁定）。若缺 Lot 登錄、缺 2D／Bin 資料、或 By Lot+Bin 模式無綁定，會跳出提示訊息。請補齊對應資料／綁定後重按 **Start**。

## 16.2 回原點 (HOME)

### Q7. `Home` 與 `Start` 帶起的回原點有何不同？

| 觸發方式 | 完成後行為 |
| --- | --- |
| 直接按 **Home** | 回原點完成後停機，HOME 監控畫面顯示 `Home finished.` 並自動關閉 |
| 按 **Start**（機台尚未回原點時） | 回原點完成後自動續跑生產 |

按 **Home** 會先彈出 `Confirm home?` 是／否確認，並強制所有軸重新回原點。

### Q8. 回原點的動作順序是什麼？

回原點的動作步序如下：

1. 判斷是否需要電源循環（必要時做伺服電源 Off→On，見 Q9）。
2. 先升起盤臂的 Z 升降氣缸並打開夾爪（若正持盤則保持夾緊、不掉盤）。
3. 放開 Loader 後鉤、再放開前擋（避免兩台 Loader 車共軌拖盤對撞）。
4. 批次把四支吸嘴的升降軸回原點。
5. 確認 Z 已升起後，批次把所有 X／Y 軸回原點。

> ⚠️ 注意：回原點防撞為硬性規則——批次回 X／Y 軸前一定先升起盤臂 Z 升降氣缸並確認到位，避免撞到下方盤；持盤時保持夾爪閉合。

### Q9. HOME 中途中止後再 HOME，要注意什麼？

可按 **Abort Home**（或回原點過程中按面板 Pause）中止：機台會停止所有馬達、清除已回原點狀態並關閉視窗。中止後機台仍要求「重新成功回原點」才能運轉。HOME 監控畫面只負責顯示進度，實際的關閉／中止判斷由系統核心掌控。

### Q10. 回原點完成後提示「請移除 Loader 盤」？

當回原點完成時若 Loader 車仍持盤（夾爪已於回原點過程中開啟、盤已鬆脫），會跳出提示要求手動移除左右兩側所有 Loader 盤。請取盤後按 `OK`，系統會清除盤的身分與盤面資料。

## 16.3 伺服／馬達警報

### Q11. 出現伺服馬達警報 (Motor Alarm) 該如何清除？

馬達警報會讓機台減速停止、放下啟動狀態，並切到回原點模式要求重新回原點。處理方式：

1. 依警報描述檢查 `[1] 電源 [2] 線路 [3] 機構`。
2. 清除驅動器故障後，重新按 **Home** 回原點。

馬達警報代碼為 `5{馬達序}{子碼0..8}` 格式，子碼涵蓋電源關、失步超扭、正／反向極限、軟體極限、位置錯誤需回原點等狀況。

### Q12. 回原點做了電源循環，伺服軸還是亮 ALM，HOME 清不掉？

這代表馬達繼電器並未切斷驅動器（A6）的控制電源（L1C／L2C），因此鎖存的伺服 ALM 無法靠馬達繼電器 Off→On 清除。此時系統會提示：「循環 MAIN 電源（斷路器）或排除驅動器故障後重新 HOME」，並中止啟動，避免進入無聲重試迴圈。

處理步驟：

1. 依提示循環 MAIN 電源（總斷路器），或排除驅動器故障。
2. 重新按 **Home** 回原點。

### Q13. 為什麼有時候伺服軸在限位上反而不報警就繼續回原點？

若系統偵測到啟用的伺服軸有 ALM，但該軸正位於 CW／CCW 限位上，會視為回原點正常、不停機繼續。只有真正「離開限位」的警報才會在運轉中觸發馬達警報並放下啟動狀態。此外，電源循環期間會略過此判斷。

## 16.4 安全感測器與「為什麼機台停了」

### Q14. 機台運轉中突然停止並彈警報，常見原因有哪些？

下列安全感測器在運轉中觸發時會停機並彈出系統警報視窗（皆提供 RETRY，排除後按 RETRY 重啟）：

| 警報 | 觸發條件 | 排除方向 |
| --- | --- | --- |
| Safety Door Open | 安全門開啟（前門／右門／左門／滑右門／滑左門／Auto6 門任一） | 關閉所有安全門後按 RETRY |
| Emergency Stop | 急停鈕被按下（任一顆）；立即停止所有馬達並鎖煞車，且清除已回原點狀態 | 釋放急停後需重新回原點 |
| Motor Power Off | 馬達電源關閉（且非上電延遲中）；清除已回原點狀態 | 重新上電後回原點 |
| Ion Fan Alarm | 離子風扇異常（僅 REALLY 模式，含時間去抖） | 確認風扇運轉後按 RETRY |
| Air Pressure Low | 氣壓過低 | 恢復氣壓後按 RETRY |

> ⚠️ 注意：依「絕不無聲停機」鐵則，任何使機台停止啟動的故障都會彈出警示，不會默默停機。

### Q15. 離子風扇警報只有偶爾出現，且只在某些模式才有？

離子風扇警報僅在 REALLY 模式生效，且帶有時間去抖：回原點中為 20 秒、穩態為 5 秒，並在馬達電源穩定（上電延遲）期間略過。因此 DUMMY／HAS_TRAY 模式不會觸發此警報。

### Q16. 狀態列顯示 `LOCK` 是什麼意思？面板按鍵沒反應？

`LOCK` 代表安全鎖（SafeLock）啟動的狀態。在此狀態下系統不會接受面板按鍵，因此前／後面板按鍵會無作用。請確認安全鎖解除後再操作。

### Q17. 主畫面狀態列各狀態代表什麼？

主畫面狀態列可能顯示：`INIT`、`HALT`、`HOMING`、`RUNNING`、`Clean Out`、`Tray Feed`、`One Cycle`、`LOCK`、`EMG`、`MOTOR OFF`、`SAFE DOOR`、`AIR`、`PAUSE`，並對應紅／綠／黃三色塔燈。

## 16.5 暫停、停止與清機

### Q18. 暫停 (`Pause`) 後可以直接續跑嗎？

可以。按 **Pause** 會讓機台在下一週期減速停止，但「保留回原點狀態」，再按 **Start** 即可續跑。

### Q19. `One Cycle` 與 `Clean Out` 有什麼限制？

| 按鈕 | 限制條件 | 行為 |
| --- | --- | --- |
| **One Cycle** | 僅允許在一般生產／清機模式且 Lot 資料就緒時使用 | 切到單循環模式，完成放料後回一般生產並停機 |
| **Clean Out** | 僅在一般生產模式時動作 | 切到清機模式，排出機台內殘料 |

### Q20. 清機完成後出現提示要選 `SKIP`？

清機完成時會彈出提示並提供 SKIP 鍵。操作員選 **SKIP** 即結束、回一般生產並停機。

> 註（定案）：HT160S **沒有 Tray Feed 功能**——`ChangeRunMode(Run_TrayFeed)` 的唯一呼叫已被註解停用、`CheckAllTrayFeedFinish` 恆回 false（stub），`Run_TrayFeed` 模式無任何入口、執行期不可達；警報視窗的 TRAY FEED 鍵在本機不會出現對應流程。

## 16.6 Real / Dummy 模式

### Q21. 如何切換 Real / Dummy？什麼時候才能切？

按 **Real / Dummy** 模式切換框循環切換，順序為 `DUMMY → HAS_TRAY → REALLY`。僅能在機台未啟動時切換；切換後會存回機台設定檔、寫入操作紀錄，並透過 SECS 事件回報主機。

### Q22. 三種模式有什麼差別？

- 離子風扇警報等「實機檢查」僅在 REALLY 模式生效。
- DUMMY 模式下馬達與氣缸仍會「實際動作」，僅略過正確性感應器確認（防撞互鎖在 DUMMY／HAS_TRAY／REALLY 三種模式皆持續生效，只有實驗室用的模擬版程式才會略過）。

> 註（定案）：三模式對 Empty/Color/Loader 的差異——**DUMMY**＝料流全虛擬（源乾用勾選框、盤在席/遺失檢查與氣缸到位確認全跳過）；**HAS_TRAY**＝真實 IO（氣缸到位確認、盤在席/遺失警報生效），但真空吸嘴檢查跳過、Top CCD 2D 走模擬循環碼；**REALLY**＝全真（真空感測報警、CCD 實體觸發、離子風扇連鎖）。詳見第 3 章定案註與第 10 章 IO 自我測試。

### Q23. 如何切換 Start Mode（Initial / Continue）？

按 **Start Mode** 切換框切換 Initial／Continue。僅能在機台未啟動時切換，切換後會存回機台設定檔並更新 Start Mode 指示圖示。

> 註（定案）：Continue（`iStartMode=1`）**對啟動流程無任何行為差異**——`Start()` 等所有執行路徑均不讀取 `iStartMode`，`CheckContinusStartIsReady()` 僅剩註解且定義不存在；差異只在畫面圖示、ini 與操作紀錄（另 Automation TCP `GET_STATUS` 有 `START_MODE=` 鏡像欄）。SECS 端無此值。詳見第 3 章。

## 16.7 Loader（進料）模組

### Q24. Loader 一直不取盤／不掃描，為什麼？

Loader 兩側（Loader1 左／Loader2 右）共用同一條 Loader-Y 導軌、共用前置疊盤機與後排排出口，因此有多重互鎖會「故意」讓某一側等待。常見原因：

1. 對側正在取盤或 CCD 掃描：另一側會暫不開始取盤（狀態互鎖）。
2. 共用前置疊盤機正被對側佔用（互斥）。
3. Loader-Y 跨側安全距不足：對側持盤且本側目標位置與對側距離小於安全間距（預設 100mm）時，拒絕移動。
4. 分類臂正佔用 Loader-Y 軸：本側等待其釋放。
5. AMR 鎖：補料交握期間凍結前置疊盤／取盤。

這些等待屬「非阻塞」設計（會自動輪詢重試），多數情況是正常排程，不是故障。

### Q25. 出現「Loader Tray Empty」怎麼處理？

代表取盤上料時推盤氣缸感測器（或模擬）判定無盤（來料疊盤已空）。回復鍵：

- **RETRY**：重新取盤。
- **TRAY END**：標記該側盤已用盡。
- **CLEAN OUT**：進入清機排空模式。

### Q26. Top CCD 相關警報（連線/讀料/2D）如何處理？

| 警報 | 意義 | 回復鍵 |
| --- | --- | --- |
| Top CCD Connect not ready | REALLY 模式且啟用 2D Bin Map 時，Top CCD 連線未就緒 | RETRY 重試 ／ SKIP 標記為 2D 掃描失敗 |
| Top CCD API not ready | 讀該格有無料失敗 | RETRY 重讀 ／ SKIP 該格設為空 ／ TRAY END 整盤改為空、結束掃描 |
| 2D code not found in any lot : `<code>` | 讀到的 2D 碼在所有 Lot 都反查不到 Bin | RETRY 重拍 ／ SKIP 標記為無 Bin 設定（導向 Error Auto） |
| Top CCD 2D no response | 3000ms 內未回傳 2D 碼 | RETRY 重拍 ／ SKIP 標記為無 Bin 設定 |

### Q27. 排出空盤前提示「Loader Tray has IC, please remove」？

代表實機排出前，底部感測器顯示盤上仍有 IC 殘留。回復鍵：**RETRY**（移除後重試）或 **SKIP**（略過、繼續排出）。

## 16.8 SortArm（分類臂）與 TrayArm（盤臂）

### Q28. 為什麼分類臂 (SortArm) 突然不能左右移動並報警？

分類臂在 X 軸移動前，每一拍都會先確認「全部吸嘴都在原點」——只要任一啟用的吸嘴升降軸不在即時 Home 感應器位置，就不准 X 移動，以免吸嘴下伸時橫移撞料。若移動中吸嘴脫離 Home 感應器（失步／漏氣），會先每拍夾停，超過去抖窗（100ms）確認後停止所有馬達並彈出：

> 「SortArm move blocked : a suck nozzle left its Home sensor (lost steps). Re-home the suckers.」(RETRY)

處理：重新讓吸嘴回原點（Home）後重試（此急停會連帶使機台停止啟動）。

### Q29. 為什麼盤臂 (TrayArm) 不能左右移動並報警？

盤臂在 X 軸移動前，每一拍都會先確認 Z 升降氣缸在上位——Z 未在上位就不准橫移，以免頭／盤在低位時橫掃撞站。若移動中離開上位超過去抖窗（100ms），會停止所有馬達並彈出：

> 「TrayArm move blocked : the Z lift left its UP sensor. Check the TrayArmZ up cylinder / air pressure.」(RETRY)

處理：檢查盤臂 Z 上位氣缸與氣壓後重試。

> ⚠️ 注意：上述兩臂防撞互鎖只有實驗室用的模擬版程式才會略過；實機 DUMMY／HAS_TRAY／REALLY 三種模式皆生效。請勿期待在 DUMMY 模式下繞過這些互鎖。

### Q30. 出現「... motor will out of limit」是什麼意思？

代表該軸目標位置超出軟體極限，系統會提示並「拒絕移動」。可能出現於分類臂 X、Loader Y、Auto Y、吸嘴間距 X、盤臂 X、Top CCD X 等軸。請檢查教導位置／極限設定後重試。

### Q31. 分類臂吸取或放料時出現吸嘴錯誤（Suck Error）？

代表真空動作失敗——吸取（Pick）或放料（Place）異常。回復鍵為 **RETRY** 或 **SKIP**，隨後系統會重置吸嘴。吸嘴錯誤碼為 `6{吸嘴序}{子碼}` 格式，子碼涵蓋取料失敗、真空感測器關、元件掉落等狀況；描述提示 `[1] 檢查真空 [2] 檢查線路 [3] 檢查氣壓／氣管`，重複發生時訊息會加註 `(Again!)`。

## 16.9 警報視窗與蜂鳴器

### Q32. 警報視窗 (Note) 上的回復鍵 (SKIP/RETRY/...) 各代表什麼？

警報視窗會依該警報實際提供的回復鍵，顯示對應按鈕：

| 按鈕 | 意義 |
| --- | --- |
| HOME & RETRY | 先回原點再重試 |
| SKIP | 跳過此料／動作 |
| RETRY | 重試造成警報的動作 |
| TRAY FEED | 補盤／送盤 |
| TRAY END | 盤子結束 |
| CLEAN OUT | 清機／清空 |

只會顯示該警報實際提供的回復鍵；純資訊提示（無回復鍵）則不顯示這些按鈕。

### Q33. 警報視窗按 `START`/`PAUSE` 都關不掉，怎麼回事？

這是刻意的安全閘控。若警報「有提供回復鍵」但操作員「尚未選任何一個」回復鍵，則 **START**（恢復）與 **PAUSE**（停機）都「不會關閉視窗」，避免未處理就帶過警報。請先選一個回復鍵（畫面觸控或實體面板鍵皆可），再按 **START** 或 **PAUSE**。只有純資訊提示（無回復鍵）可直接關閉。

### Q34. 警報還沒解決，可以先讓蜂鳴器停下來嗎？

可以。按 **Off Buzzer**：會鎖存消音狀態並關閉蜂鳴，使警報蜂鳴不再重新響起；但「警報視窗仍開啟」，仍需處理警報。實體 **ALARM RESET** 鍵也有相同的消音效果。

### Q35. 為什麼安全門開／急停時只亮紅燈、不一定有蜂鳴聲？

警報蜂鳴只由警報視窗（Note）觸發。純安全感測（急停／安全門／氣壓／離子風扇）若當下沒有對應的警報對話框，只會亮紅燈而不發蜂鳴。

> 註：各運轉狀態 Music Select **程式預設值＝[0] Mute**（全靜音）；實際值由 Maintenance 塔燈頁設定並存於號誌燈 ini。
>
> 【待補（現場）：SwMusic1..4 各音樣式（旋律/長短）的實際聲音需現場聆聽記錄。】

### Q36. 警報代碼從哪裡查？

開機時系統會依氣缸／馬達／吸嘴設定表「動態產生」整份警報代碼目錄，並輸出到 `system\AlarmList.csv`（欄位：AlarmCode、AlarmType、E_ErrMessage、C_ErrMessage、E_Description、C_Description）。可開啟此 CSV 查閱機台所有可能的警報。

> 註（定案，2026-07-16 查核）：現行 `system\AlarmList.csv`（576 筆）的 `C_ErrMessage`/`C_Description` **仍為英文**（與 E_ 欄相同）；中文化為待辦工作項。完整清單見附錄 D。

### Q37. 提示框（OK / 是否確認）跟全警報視窗有什麼不同？

兩者是不同的視窗：

- 全警報視窗（Note）：會停機、面板紅色閃爍、發蜂鳴並提供回復鍵。
- 輕量提示框：分為「僅 OK（會停機）」、「僅 OK（不停機，純資訊）」、「是／否確認（不停機、不發蜂鳴）」三種。

## 16.10 狀態快照（Hang up）

### Q38. 機台異常時要怎麼留存現場資料給工程分析？

按 **Store Hangup**（狀態快照）會手動觸發一次 State Record 快照，把任務歷程、機台狀態與設定打包成 zip 供離線分析，並自動用檔案總管開啟該資料夾。發生不易重現的異常時，建議先做一次快照再排除。
