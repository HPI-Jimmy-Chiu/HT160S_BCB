# 第 14 章　各模組運作流程

本章逐一拆解 HT160S 五個製程模組的運作流程：Loader 進料、Color 顏色（身份盤供應）、Empty 空盤、SortArm 分類臂（含 4 個吸嘴）／TrayArm 盤臂、Auto1～6 出料堆疊。每個模組以「功能 → 動作時序 → 互鎖與安全 → 操作員可見狀態」的順序說明，重點放在各模組之間的防撞互鎖與跨模組交握，這些是整機能否安全連續運轉的工程核心。

所有模組共通的設計原則：

- 皆為**純邏輯／控制模組**，多數無自身畫面，由主控迴圈逐拍呼叫，子動作完成才往下一步。
- 所有等待都以「未完成就重試」實作，不會卡住整機（警報彈窗除外）。
- 教導位置與編碼器位置以 **1/100mm** 為單位（100 units/mm）。
- 防撞互鎖（吸嘴回原點、Z 上位確認等）**只有實驗室用的模擬版程式才會略過**；實機 DUMMY／HAS_TRAY／REALLY 三種模式皆持續生效，因為 DUMMY 下馬達與氣缸仍會實際運動。

## 14.1　Loader 進料模組（TLoaderModule）

### 14.1.1　功能

進料模組負責雙側（Loader1 左／Loader2 右）來料盤的取放、頂部 CCD 掃描索引、與空盤排出。每一側透過共用的 **Loader-Y 軸**把盤子移到取盤位、用前置疊盤氣缸分出一盤、夾緊上料，再帶到 **Top CCD** 下方逐格掃描每顆 IC（讀 Bin 與 2D 條碼），結果寫入該側盤面資料供 SortArm 分類臂取料分類。CCD 掃描完成的一側即標記為可被分類臂接管。盤面全部排空後排到後方供 TrayArm 盤臂取走。

| Loader 2D Left／Right 盤面格點 | 表格 | Tray Status 分頁左右盤面格點（預設 4×5），鏡射該 Loader 車道生產盤內容（每格顯示 IC 掃描／分類狀態） |

### 14.1.3　動作時序

#### 單側自動進料循環（每側獨立）

狀態序列：閒置 → 取盤 → CCD 掃描 → 等待分類 →（分類臂接管）分類中 → 往後排出，排出後回到閒置。

1. 若 Loader-Y 上無盤、對側未在取盤或掃描、且未被 AMR 鎖定 → 開始取盤；若已有盤 → 直接進入 CCD 掃描。
2. 取盤完成後，若對側未在掃描 → 進入 CCD 掃描。
3. 逐格 CCD 掃描完成後 → 進入排出判斷。
4. 若 Loader-Y 軸未被分類臂佔用：盤面仍有 IC → 標記為等待分類、等分類臂來取；若整盤已空且後方／對側可排出 → 開始排出空盤。
5. 空盤排到後方後 → 回到閒置，重新循環。

#### 取盤上料

1. 取得共用前置疊盤機的使用權（兩側互斥）。
2. 把 Loader-Y 移到該側取盤位。
3. 推盤、斜靠氣缸退回。
4. 從前置疊盤分出一盤。
5. 斜靠、推盤氣缸推出，夾緊盤子。
6. 確認有盤（模擬看「模擬供盤勾選」；實機看推盤氣缸 On 感測器）→ 建立盤面（每格先標為未檢查）；無盤則跳 `Loader Tray Empty` 警報。
7. 釋放前置疊盤機使用權，完成。

#### 前置疊盤分一盤（生產與 Teach 測試共用）

1. 頂升缸 1 上升。
2. 頂升缸 1 到位 → 頂升缸 2 上升。
3. 頂升缸 2 到位 → 分張缸伸出（分張），起延時。
4. 延時到 → 頂升缸 2 下降（放下最底一片）。
5. 頂升缸 1 仍到位 → 分張缸收回。
6. 頂升缸 1 復位後關閉，完成。

#### 頂部 CCD 掃描與索引

1. 盤面仍有未檢查的格 → 繼續掃；全部掃完且對側未在等待則標記為等待分類。
2. 以 Y 列為外圈、X 為內圈**蛇行**（每列端點翻轉方向）找下一個未檢查的格。
3. 把 Top CCD 的 X 與 Loader-Y 移到該格，設 100ms 安定延時。
4. 讀該格有無料（模擬／未啟用 CCD 時視為有料）；寫入盤面。若啟用 2D Bin Map 且該格有料，觸發 Top CCD 拍照，設 3000ms 等待。
5. 取 2D 條碼，反查所屬 Lot 與 Bin，寫入該格；By Lot+Bin 模式則綁定對應 Auto；查不到即跳警報。

> 註（定案）：`ReadTopCcdBin` 實機路徑（UseCCD 開、非模擬）確為 stub（`bOk=false` 回 `EMPTY_IC`，呼叫端跳 `WAR0330 Top CCD API not ready`，可 SKIP/RETRY/TRAY_END）。實機的 IC 有無/Bin 判定**不靠此函式**：真正來源是 `ReadTopCcd2DCode`（僅 REALLY＋`bUseTopCcd` 才實連 TopCcdSocket）取得 2D 碼後，由 `LotRegistry.FindByCode2D` 反查匯入的 2D/Bin 資料——即實機恆走 2D 路徑。

#### 空盤排出

1. 比較兩側 Loader-Y 位置，避免越過對側，且後排底部未佔用才繼續。
2. 後方仍有盤則等待。
3. 把 Loader-Y 移到該側排出位；實機若底部感測器仍顯示有 IC 則跳「請移除」警報；推盤／斜靠氣缸復位。
4. 推盤氣缸退回 → 標記後方已有盤。
5. 斜靠氣缸退回 → 清空盤面。
6. 把 Loader-Y 移回取盤位，完成。

### 14.1.4　互鎖與安全

> ⚠️ 注意：**跨側 Loader-Y 安全距離互鎖**。兩側共用同一導軌，當對側夾著盤、且本側目標位置與對側位置間隔小於安全間距（預設 100mm）時，拒絕移動、等待。安全間距設為 0 以下視為停用此互鎖。

> ⚠️ 注意：**Loader-Y 軸所有權互鎖**。Loader 與分類臂不可同時移動 Loader-Y。排出判斷階段若 Loader-Y 正被分類臂佔用則等待，由「取得→確認持有→釋放」三段交握管理。

其他互鎖：

- **軟體極限**：Loader-Y／Top CCD X 移動前先檢查軟體極限，超界跳警報並拒動。
- **共用前置疊盤機互斥**：同時只允許一側操作前置疊盤機。
- **對側忙碌互鎖**：一側正在取盤或 CCD 掃描時，對側不開始取盤。
- **排出前互鎖**：須對側位置、後排底部與後方皆未佔用才排出空盤。
- **實機排出前殘料檢查**：底部感測器顯示仍有 IC 時跳 `Loader Tray has IC, please remove`。
- **AMR 鎖**：交握補料期間凍結前置疊盤／取盤。

### 14.1.5　AMR/AGV 補料交握

1. 判斷來料是否缺料：模擬看模擬進料計數是否歸零；實機看 Loader 進料端感測器為空 → 呼叫 AGV。
2. 上鎖：交握期間凍結前置疊盤／上料。
3. 確認可交接：三顆前置疊盤氣缸都回到原位，才可讓 AGV 補料。
4. 確認補料完成：實機 Loader 進料端感測器變為有料。
5. 模擬補料：把模擬進料計數補滿。

### 14.1.6　設定

| 設定項目 | 範圍/預設 | 說明 |
| --- | --- | --- |
| Loader-Y 跨側安全間隔 | 預設 10000（=100mm）；`<=0` 停用 | 兩側 Loader-Y 車跨側最小安全間隔（1/100mm），設定檔 `[Safety] LoaderYSafeDistance` |
| 模擬-Loader 疊盤盤數 | 模擬補料用 | 模擬 Loader 來料疊盤盤數（每次取盤遞減，0 缺料呼叫 AGV） |
| 分流模式 | 0/1/2 | 分流模式；1=By Lot+Bin（2D 反查後綁定 (Lot,Bin)→Auto）、2=By Lot+PassFail（綁定 (Lot,PASS/FAIL)→Auto，PASS/FAIL 由 Bin==Pass Bin 導出、掃描時凍結） |
| 啟用 2D 條碼讀取 | 開/關 | 是否啟用 Top CCD 2D 條碼讀取與 Bin 反查（關閉只讀有無料） |
| Loader 取盤位 Y | 教導值 | 各側 Loader-Y 取盤位（1/100mm） |
| Loader 空盤排出位 Y | 教導值 | 各側空盤排出位 |
| Loader CCD 第一格 Y 起點 | 教導值 | 各側 CCD 掃描第一格 Y 起點 |
| Top CCD X 第一格起點 | 教導值 | Top CCD X 掃描第一格起點（兩側共用） |
| 盤面格數 X/Y | X 1..50；Y 1..20 | 盤面格數（由配方讀入） |
| 盤面格距 X/Y | 配方值 | 盤面格距，計算各格 CCD 位置用 |
| 運轉模式（Real/Dummy/HasTray） | DUMMY/HAS_TRAY/REALLY | 運轉層級，影響感測器/CCD/拍照是否走實機路徑 |

### 14.1.7　警報與排除

| 警報 | 意義 | 排除 |
| --- | --- | --- |
| `Loader Tray Empty` | 取盤時氣缸感測器／模擬判定無盤（來料疊盤已空） | RETRY 重取／TRAY END 標記該側盤已用盡／CLEAN OUT 進入清機排空模式 |
| `Loader Y motor will out of limit` | Loader-Y 目標超軟體極限 | 檢查教導位置／極限設定後重試 |
| `Top CCD X motor will out of limit` | Top CCD X 目標超軟體極限 | 檢查教導位置／極限設定 |
| `Top CCD Connect not ready` | REALLY 且啟用 2D Bin Map 時 Top CCD 連線未就緒 | RETRY 重試／SKIP 標記為 2D 掃描失敗 |
| `Top CCD API not ready` | 讀該格有無料的 CCD 結果失敗 | RETRY 重讀／SKIP 該格設為空／TRAY END 整盤未檢查改為空 |
| `2D code not found in any lot : <code>` | 2D 條碼在所有 Lot 中反查不到 Bin | RETRY 重拍／SKIP 標記為無 Bin 設定（導向 Error Auto） |
| `Top CCD 2D no response` | 3000ms 內 Top CCD 未回 2D 條碼 | RETRY 重拍／SKIP 標記為無 Bin 設定 |
| `Loader Tray has IC,please remove` | 實機排出前底部感測器顯示盤上仍有 IC | RETRY 移除後重試／SKIP 略過排出 |

## 14.2　Color 顏色模組（TColorModule）

### 14.2.1　功能

顏色模組負責供應**身份盤（identity tray）**給後段 TrayArm 盤臂。兩種模式：TraySupply（供盤，預設）與 SortBin（分 Bin，目前為空殼）。供盤時先在前方收／讀位置由破棧氣缸分離一片盤並夾住，透過 **Color 2D CCD** 讀取盤上 2D TrayID，再用 **ColorY 軸**把載盤搬到後方取盤位置讓盤臂夾取。實際供盤動作只有在收到 AMR／盤臂真正需求時才推到輸出位置並讀碼，避免提前呈現身份盤。

> Color 模組無自身 UI 畫面，由主控迴圈逐拍驅動。

> ⚠️ 注意：**安裝閘**。若未安裝 Color 區（硬體安裝頁未勾「是否安裝 Color 輸出區」），整個模組停用、不動作。

### 14.2.2　動作時序

ColorY 軸幾何：Y＝前／後（相對操作者）、X＝左／右、Z＝上／下。供盤為**兩段式流程**（仿 Empty）：第一段先把一片盤分離到前方緩衝；第二段只有在有需求時才推到輸出讀碼。

#### TraySupply 供盤主流程

1. 更新感測器狀態；若為 SortBin 模式改走分 Bin 流程。
2. 閒置決策：
   - 若被 AMR 上鎖 → 暫停（凍結前段破棧）。
   - 若盤已就緒且已被夾走 → 釋放空位。
   - 若盤已就緒但尚未被夾走 → 回閒置，等盤臂取走。
   - 若前方無暫存盤且（進料端有盤或模擬）→ 預先分離一片盤到前方緩衝。
   - 若前方已有暫存盤且有供盤需求 → 推到輸出並讀碼；否則回閒置。

#### 前方破棧分盤

1. 依序伸出頂升缸 1、頂升缸 2（升盤）。
2. 伸出分張缸（分盤），起 5 拍延時。
3. 延時到 → 頂升缸 2 退回，再延時。
4. 分張缸退回，再延時。
5. 頂升缸 1 退回，邏輯上標記前方已有盤（無前段感測器，僅邏輯暫存）並結束。

#### 供盤 + 讀碼 + 搬到後方

1. 把 ColorY 移到前方收／讀位置。
2. 更新感測器狀態；若輸出已有盤直接進入讀碼；若無前方暫存盤且非模擬，清除供盤需求並結束。
3. 標準雙缸夾盤（斜靠缸靠 + 推盤缸推，不做推缸到位確認）。
4. 更新感測器狀態；若底部感測器有效、輸出無盤且非 DUMMY → 跳 `Color supply tray is not ready` 警報；否則標記前方無盤並開始讀 2D 碼。
5. 等待 2D 讀碼完成（取得 TrayID）。
6. 把 ColorY 移到後方取盤位置；成功後標記盤已就緒、尚未被夾走、清除供盤需求並結束。

#### Color 2D CCD 讀碼

1. 若為模擬 → 偽造一個 TrayID；若未啟用 Color CCD → 空碼結束；否則建立連線。
2. 把 Color CCD 的 X 移到讀碼位置（含軟體極限檢查）。
3. 未連線 → 跳 `Color CCD connect not ready`（RETRY／SKIP）；已連線則觸發拍照，起 3000ms 延時。
4. 輪詢取碼填入 TrayID 後結束拍照；逾時則跳 `Color CCD 2D no response`（RETRY／SKIP）。

#### 釋放／清盤

依序退回推盤缸、斜靠缸、後升缸、頂升缸 2、頂升缸 1、分張缸，完成後清除「盤就緒／盤已夾走／輸出有盤」狀態並結束。

### 14.2.3　跨模組交握

**TrayArm 盤臂取盤交握**：

1. 盤臂需要盤時：若 Color 尚未備妥盤，發出供盤需求觸發供盤。
2. 盤就緒被夾走時：取得該盤的 2D TrayID，並通知 Color「盤已被夾走」。

**AMR（P3 ColorTray）補料交握**：

1. 判斷是否缺料：模擬看模擬進料計數是否歸零；實機看 Color 進料端感測器為空。
2. 確認可交接：前段三顆升／分盤缸都在原位。
3. 上鎖，凍結前段破棧。
4. 確認補料完成：模擬自動完成；實機等 Color 進料端感測器變為有料。
5. 模擬補料：把模擬進料計數補滿（僅模擬）。

### 14.2.4　互鎖與安全

> ⚠️ 注意：**AMR 鎖**。被 AMR 上鎖時，補料期間凍結前方破棧，避免與 AMR 補料動作衝突。

> ⚠️ 注意：**供盤需求閘（just-in-time）**。只有在收到供盤需求時才會供盤，確保身份盤只在 AMR／盤臂真正有需求時才呈現／掃描，不提前供盤。

其他互鎖：

- **ColorY 軟極限**：移動前先檢查軟體極限，超限跳 `Color Y motor will out of limit`，不真的移動（但不卡住供盤流程）。
- **Color CCD X 軟極限**：讀碼移動前檢查軟體極限，超限時跳過移動。
- **輸出盤確認**：供盤時若底部感測器啟用、輸出無盤且非 DUMMY → 跳 `Color supply tray is not ready`（RETRY；DUMMY 不報）。
- **CCD 連線／讀碼失敗**：以 RETRY／SKIP 處理，跳過時 2D 碼留空、供盤流程繼續。

### 14.2.5　設定

| 設定項目 | 範圍/預設 | 說明 |
| --- | --- | --- |
| Color 區是否安裝 | 開/關 | Color 區是否安裝；未安裝時整個模組停用 |
| Color 模組模式 | 預設 TraySupply | 模組模式：TraySupply 供盤 / SortBin 分 Bin |
| Color 讀 2D 位置 Y | 教導值（1/100mm） | ColorY 前方收/讀 2D 位置 |
| Color 取盤位置 Y | 教導值 | ColorY 後方盤臂取盤位置 |
| Color 讀 2D 位置 X | 教導值 | Color 2D CCD 讀碼時的 X 位置 |
| 啟用 Color CCD | 開/關（設定檔 `[ColorCCD] Enable`） | 未啟用時跳過相機、2D 碼留空 |
| 模擬-Color 進料堆盤數 | 整數 | 模擬 Color(P3) 進料堆最大盤數 |
| 2D 讀碼逾時 | 3000 ms | Color 2D CCD 一次拍攝/讀碼回應逾時 |
| 破棧/夾盤延時 | 各段 5 tick | 分盤動作各段安定延時 |

> 註（定案）：`iSupplyThreshold`（預設 100）與 `NotifyICPlaced`/`iICCount` 為**遺留碼**——全程式無任何呼叫點（`iICCount` 僅出現在 FeederDecision 除錯 dump），不影響供盤行為。

### 14.2.6　警報與排除

| 警報 | 意義 | 排除 |
| --- | --- | --- |
| `Color supply tray is not ready` | 推盤後輸出底部感測器未偵測到盤（非 DUMMY） | RETRY 重試（重跑供盤） |
| `Color CCD connect not ready` | Color 2D CCD 未連線／未就緒 | RETRY 重連／SKIP 跳過讀碼（2D 碼留空） |
| `Color CCD 2D no response` | 觸發拍攝後 3000ms 未取得結果 | RETRY 重拍／SKIP 跳過 |
| `Color Y motor will out of limit` | ColorY 目標超軟極限 | 檢查／修正 ColorY 的前方讀碼位或後方取盤位教導值 |
| `Color CCD X motor will out of limit` | Color CCD X 目標超軟極限 | 檢查／修正 Color CCD 讀碼 X 位教導值 |

> 註（定案）：Color 站作為 Bin 區收 IC 的功能確為空殼、固定不接受 IC——此功能**未實作，屬預留介面**；Color 站目前僅作身分/reject 盤供給，不收分選 IC。

## 14.3　Empty 空盤模組（TEmptyModule）

### 14.3.1　功能

空盤模組負責供應與處理空料盤。從前段堆疊以雙缸頂升／分張機構逐片取下空盤（GoDown），再以斜靠＋推送雙缸夾住、由 **EmptyY 軸**搬移至放料位送入後段（Feed），供 TrayArm 盤臂取走。批次結束或需回收時可反向把後段料盤重新夾起、上推回前段堆疊（GoUp／Return）。

> **盤態鎖存（latch）約定**：盤子下來（GoDown 完成）＝有盤；被 EmptyY 軸／盤臂夾走＝沒盤。模擬／DUMMY 下不讀實體感測器，狀態完全由動作序列鎖存維護。本模組無自身 UI 畫面。

### 14.3.2　動作時序

#### 主排程（閒置決策優先序）

1. 若被 AMR 上鎖 → 本回合不啟動任何新動作（凍結前段拆堆）。
2. 更新感測器狀態後依優先序：
   - **回收**：若需回收料盤 → 上推回收。
   - **前段補盤**：若前段無盤且批次未結束 → 從堆疊取下一片。
   - **送後段**：若後段無盤且批次未結束 → 把前段料盤送到後段。
   - **批次結束回收**：若批次已結束且前段仍有盤 → 上推回收。

#### 取下空盤（前段拆堆）

1. 頂升缸 1 上升。
2. 頂升缸 1 到位 → 頂升缸 2 上升。
3. 頂升缸 2 到位 → 分張缸伸出，起 5 拍延時。
4. 延時到 → 頂升缸 2 下降（放下最底一片），再延時。
5. 頂升缸 1 仍到位 → 分張缸收回，再延時。
6. 頂升缸 1 復位。
7. 檢查前段進料感測器：啟用、讀不到盤且非 DUMMY → 標記前段無盤並跳 `Front Empty Tray Is Miss Error`；否則標記前段有盤、完成。

#### 送盤到後段（雙缸夾取＋Y 軸搬移）

1. 一次性把斜靠缸、推盤缸復位，清除中止留下的殘餘動作。
2. 更新感測器狀態；若後段已有盤則不需送、直接結束。
3. 把 EmptyY 移到上料位。
4. 以共用雙缸夾盤流程夾盤：夾好 → 繼續；推缸未到位 → 跳 `Empty Push Tray Miss`（RETRY）。
5. 把 EmptyY 移到放料位，標記前段無盤。
6. 推盤缸退回 → 斜靠缸退回。
7. 檢查底部感測器，設定後段有盤狀態，完成。

> ⚠️ 注意：送盤流程開頭的復位動作只能做一次。**切勿在每次推缸動作前都復位**，否則會重啟動作序列而卡住。

#### 上推／回收料盤（回收 / 批次結束）

1. 頂升缸 1 上升 → 到位後分張缸伸出（延時）。
2. 頂升缸 2 上升 → 到位後分張缸收回（延時）。
3. 頂升缸 2 下降 → 頂升缸 1 到位 → 頂升缸 1 退回，標記前段無盤。
4. 若後段有盤：把 EmptyY 移到放料位 → 斜靠缸靠 → 推盤缸推 → 把 EmptyY 移回上料位 → 推盤缸退 → 斜靠缸退，標記前段有盤、清除後段／底部狀態，完成。

#### 雙缸夾盤共用子程序

結果分三種：進行中、夾好、推缸未到位。動作固定為**斜靠缸先、推缸後**：

1. 斜靠缸先伸出到位。
2. 推盤缸伸出到位；若不需安定確認則立即回報夾好，否則啟動安定延時。
3. 安定後確認推缸到位 → 回報夾好；否則退缸。
4. 退回推盤缸 → 回報推缸未到位，由呼叫端警報／重試。Empty 模組使用 5 拍安定時間。

### 14.3.3　互鎖與安全

> ⚠️ 注意：**EmptyY 防撞盤臂**（僅實機生效）。若盤臂 Z 上升缸未到位、且盤臂 X 已進入 Empty 干涉區，則 EmptyY 拒絕移動，避免與盤臂干涉。

其他互鎖：

- **EmptyY 軟體極限**：超出軟體極限時跳 `Empty Y motor will out of limit` 並拒動；軸不存在時直接不動作。
- **料盤遺失檢查加 DUMMY 條件**：送盤／拆堆的感測檢查僅在非 DUMMY 時進行（DUMMY 不讀實體感測，盤態由鎖存維護）。
- **模擬／DUMMY 不讀實體感測**：因有盤輸入為 active-low，無 IO 卡時會誤判成「有盤」而清掉鎖存、卡住模組。
- **AMR 鎖**：被 AMR 上鎖時凍結前段拆堆。
- **雙缸夾盤推缸到位確認**：安定後若推缸感測器未到位則退缸並回報未到位，避免夾不到盤就搬移。

### 14.3.4　AMR 補料交接（P2）

1. 確認可交接：前段三缸（頂升缸 1／2 ＋ 分張缸）都回到原位。
2. 上鎖期間不啟動新拆堆。
3. 判斷是否缺料：模擬看模擬進料計數是否歸零／實機看 Empty 進料端感測器為空 → 觸發呼叫 AMR。
4. 確認補料完成：模擬永遠為真／實機等 Empty 進料端感測器變為有料。
5. 模擬補料：把模擬進料堆補滿。

### 14.3.5　設定

| 設定項目 | 範圍/預設 | 說明 |
| --- | --- | --- |
| Empty 取盤位置 Y | 教導值（1/100mm） | EmptyY 軸上料位置（取盤/夾盤位） |
| Empty 放料位置 Y | 教導值 | EmptyY 軸放料位置（送料盤入後段位） |
| 盤臂進 Empty 干涉 X 門檻 | 教導值 | 盤臂 X 進入 Empty 干涉區的 X 門檻，用於防撞判斷 |
| 模擬-Empty 進料堆盤數 | 設定值 | 模擬 Empty 輸入堆滿匣盤數（每次下降消耗 1） |
| Empty 夾盤安定時間 | 5 tick | 雙缸夾盤後安定時間，>0 才做安定+確認 |
| 頂升/分張延時 | 5 tick | 頂升/分張各步驟延時 |

### 14.3.6　警報與排除

| 警報 | 意義 | 排除 |
| --- | --- | --- |
| `Empty Push Tray Miss` | 送盤夾取時推缸未到位 | RETRY：重新移到上料位再夾 |
| `Bottom Empty Tray Is Miss Error` | 送盤完成後底部感測器讀不到料盤（非 DUMMY） | RETRY 重來／SKIP 清狀態跳過 |
| `Rear Empty Tray Is Miss Error` | 略過底盤後後段仍讀不到料盤（非 DUMMY） | RETRY：重來 |
| `Front Empty Tray Is Miss Error` | 拆堆完成後前段感測器讀不到料盤（非 DUMMY） | RETRY：重新拆堆 |
| `Empty Y motor will out of limit` | EmptyY 目標超軟體極限 | 資訊提示，拒絕該次移動 |

> 註（定案）：Empty 模組的「Lot 完成」旗標只在**清機（Clean Out）且盤臂收尾完成**時為 true（供 drain 分支判斷），與 Lot Start/End 流程無關。

## 14.4　SortArm 分類臂與 TrayArm 盤臂模組

### 14.4.1　功能

分類臂與盤臂是兩個無自身畫面的機台控制模組，由主流程逐拍（非阻塞）驅動。

- **分類臂**：用一排吸嘴（4 個吸嘴升降軸）從 Loader 來料盤把 IC 逐顆吸取，依 Bin／Lot 路由放到 Auto1～6 出料盤。採**單顆取放**：每一行程只取／放一顆，每圈重新掃盤逐顆把整盤排空。
- **盤臂**：單軸搬運臂，從 EmptyTray／Loader 後方／Color 取空盤，搬送並放到目標 Auto 後方（或回收到 EmptyTray）。

> ⚠️ 注意：兩臂都內建防撞互鎖。分類臂在 X 移動前須**全部吸嘴回原點**；盤臂在 X 移動前須 **Z 升降氣缸確認在上位**。這些互鎖只有實驗室用的模擬版程式才會略過，實機 DUMMY／HAS_TRAY／REALLY 三種模式皆持續生效（因 DUMMY 下馬達與氣缸仍實際運動，僅略過正確性感測器確認）。

### 14.4.2　SortArm 動作時序

#### 取放主迴圈

1. **待命／派工**：若手上已持有 IC → 去放料；否則向 Loader 詢問待分類的 Loader 編號 → 去取料；清機模式且兩側 Loader 皆排空 → 標記清機完成。
2. **取料**：從 Loader 取料完成後去放料。
3. **放料**：放到 Auto；仍持料則繼續放，否則回待命。

#### 取料子流程

1. 掃整盤找第一顆可取格，選出能對到該欄的吸嘴；取得 Loader-Y 軸的獨佔權，失敗則清除選擇返回。
2. 全吸嘴升到安全高度。
3. 把吸嘴間距軸調到盤距。
4. 計算並移動到取料 X／Y。
5. 再確認仍持有 Loader-Y 軸，失去則退出；否則把選定吸嘴下降到 Loader 取料高度。
6. 抽真空吸取，成功後把資料轉到吸嘴、清空來料盤格、標記已持有 IC。
7. 升回安全高度 → 釋放軸 → 完成。
8. （交握中斷退出）：升安全高度、釋放軸、清除取料選擇後返回。

#### 放料子流程

1. 依每顆吸嘴的路由 Bin 對到目標 Auto，找該 Auto 盤第一個空格並組出連續的吸嘴群。
2. 升安全高度 → 調間距 → 移到放料 X／Y。
3. 把選定吸嘴下降到 Auto 放料高度。
4. 破真空放料，成功後寫入 Auto 盤格、累加該盤 IC 計數、清空吸嘴。
5. 升回安全高度 → 完成。

### 14.4.3　TrayArm 動作時序

#### 搬運主迴圈

派工優先序：1) 回收滯留在 Loader 後方的空盤；2) AMR 模式依 Auto 需求堆疊 identity／cover／normal 盤；3) Normal 模式從 EmptyTray 補空盤到 Auto；皆為需求驅動。

1. **待命／派工**：若意外仍持盤且有未完成工作（中斷後可續）→ 續放；否則派工，有工作則去取盤。
2. **取盤**：取盤完成後設為搬運中；回收工作會決定供 Auto 或回收 EmptyTray，其它一律送 Auto；接著去放盤。
3. **放盤**：放盤完成後回到待命、清除工作。

#### 取盤子流程

1. 升 Z（必須有上位感應器確認）。
2. 把盤臂 X 移到取料位（回收＝Loader 後方、AMR identity＝Color、其餘＝EmptyTray 後方）。
3. 下降。
4. 前、後兩夾爪伸出夾住盤，啟動 3 拍延時。
5. 延時到 → 升 Z。
6. 依工作別通知來源（Loader 通知後方盤已取走／Color 取得 TrayID 後通知盤已被夾走／EmptyTray 標記後方無盤），標記已持盤。

#### 放盤子流程

1. 若目的地是 EmptyTray（回收）則改走回收放盤流程。
2. 升 Z → 把盤臂 X 移到目標 Auto 位（回收路徑移到 EmptyTray 位並等後方清空才下放）。
3. 下降 → 兩夾爪放開（3 拍延時）→ 升 Z。
4. 通知目的端（AMR 帶盤種＋TrayID／Normal 標記 Auto 後方已有盤／回收通知回收完成），標記未持盤。

### 14.4.4　互鎖與安全（防撞核心）

> ⚠️ 注意：**分類臂全吸嘴回原點互鎖**。每次 X 移動前都檢查每個啟用的吸嘴升降軸當下是否在原點（**讀即時 Home 感應器，非黏滯旗標**）；任一不在原點即不准 X 移動，避免吸嘴下伸時橫移撞料／撞框。

> ⚠️ 注意：**分類臂失步去抖 + 急停**。確認吸嘴非原點時先每拍夾停 X 軸；超過去抖窗（100ms）才判定為真失步 → 停止所有馬達並彈出系統警報（RETRY，連帶使機台停止啟動）。

> ⚠️ 注意：**盤臂 Z 上位互鎖**。每次 X 移動前都檢查 Z 升降氣缸是否在上位；Z 未在上位即不准 X 橫移，避免頭／盤在低位時橫掃撞站。失步去抖同分類臂（超過 100ms → 停止所有馬達並彈出系統警報）。

> ⚠️ 注意：**盤臂升 Z 真上位確認**。升 Z 須氣缸伸出成功且上位感應器為真才算完成（避免 DUMMY 下立即回報完成、讓 X 在頭未實升時起步）；雙線圈 Z 升前先關下降缸。

其他互鎖：

- **分類臂 X 軸軟極限**：X 移動前先檢查軟體極限，超限拒動。
- **分類臂單取左緣下限**：取料允許基準 X 為負以取左緣欄，但不得低於吸嘴數的負值範圍，超過視為壞資料拒絕。
- **分類臂 Loader-Y 雙車安全距**：移動 Loader-Y 前檢查共軌對向車安全距；不安全則靜默等待重試；DUMMY 下仍生效。
- **分類臂軸獨佔交握**：取料前先取得軸獨佔權，下降吸取前再確認仍持有；失去則升安全高度、釋放軸、清除選擇安全退出。
- **盤臂 X 軸軟極限**：X 移動前先檢查軟體極限，超限拒動。
- **防撞旁路範圍**：上述兩臂防撞互鎖只有實驗室用的模擬版程式才會略過；實機三種模式皆生效。

| 吸嘴吸取／放料錯誤 | 吸取或放料真空動作失敗 | RETRY／SKIP；隨後系統會重置吸嘴 |

> 註：夾爪/升降實體 IO 點位（`system/IO_Table.csv`，格式 Lane/IP/Port/Bit）：`C_TrayArm_FrontClamp`＝0/0/2/6、`C_TrayArm_RearClamp`＝0/0/2/7（兩者 OnDelay/OffDelay 500/500）、`C_TrayArmZ_Up`＝0/0/2/5、`C_TrayArmZ_Down`＝0/0/2/4（各自 On 感測在 Port1 同 Bit）。分類臂吸嘴為 `Suck1~Suck4`（Sucker，0/0/1/0~3）。
>
> 【待補（現場）：`ArmDelay.Set(3)` 的 3 拍對應實際毫秒數取決於主迴圈實際週期（標稱約 1ms/拍，即約 3ms），列入現場動態驗證清單量測。】

## 14.5　Auto1~6 出料堆疊模組（TAutoModule）

### 14.5.1　功能

出料堆疊模組管理 6 個出料堆疊站（Auto1～Auto6），純控制模組，無自身 UI 畫面。每站把分料後的盤子在「後方接收位」、「作業位」與「堆疊車」之間搬移：盤臂把空盤（或 AMR 模式的 identity／cover／normal 盤）放到後方，接著用斜靠／推盤氣缸把盤夾入並由 **AutoY 軸**帶到作業位供分類臂放 IC，盤子滿料後以升盤氣缸把盤堆入堆疊車。

> **Bin→Auto 的路由判定不在本模組**，而由分類臂依 Bin→Auto 對應表或動態綁定決定後，再把盤放入對應 Auto。

### 14.5.2　動作時序

#### 正常出料堆疊循環

1. 更新各站狀態，AMR 模式處理滿車。
2. 若找到「車內無盤且後方有盤」的站 → 把後方盤夾入並帶到作業位。
3. 若找到滿料的站 → 把滿盤堆入堆疊車。
4. 清機模式下清空全部站。

#### 進盤上料（後方盤→作業位）

1. 選站（車內無盤且後方有盤）。
2. 把 AutoY 移到取盤位；檢查底部感測器確認到位，缺盤跳 `Auto%d Feed Tray Miss`。
3. 斜靠氣缸靠盤。
4. 推盤氣缸推盤，延時 5 拍後確認到位；未到位則退回並跳 `Auto%d Push Tray Miss`。
5. 把 AutoY 移到作業位。
6. 標記車內已有盤、清除後方旗標；AMR 模式記錄盤種與 2D TrayID，identity／cover 盤直接標為滿料。

#### 出盤堆疊（作業位滿盤→堆疊車）

1. 選滿料站（跳過 AMR 上鎖的站）。
2. 把 AutoY 移到排出位，清除車內盤旗標，並向 SECS 主機發事件回報（各 Auto1～6 對應各自事件）。
3. 推盤氣缸退回 → 斜靠氣缸退回。
4. 把 AutoY 移到取盤位，延時 5 拍。
5. 升盤氣缸伸出→延時 5 拍→退回，把盤堆入車。

#### 全站清盤（清機模式）

須分類臂先完成清機才進入。六站同步：AutoY 到排出位 → 推盤缸退回 → 斜靠缸退回 → 升盤缸伸出 → 延時後升盤缸退回 → AutoY 回取盤位 → 清除旗標、清空盤面、標記清機完成。

### 14.5.3　跨模組與資料流

1. **盤子來源**：盤臂放盤到某 Auto 後方 → 通知該站後方已收到盤，鎖存並記錄盤種與 TrayID。
2. **需求拉取**：各站回報想要的盤種（AMR 依堆疊順序 identity→cover→normal；Normal 模式恆為空工作盤）；再把第一個要盤的站回報給盤臂。
3. **Bin→Auto 路由（不在本模組）**：分類臂依模式決定目標 Auto：(a) By Lot+Bin 模式查動態綁定；(b) Normal 模式查 Bin→Auto 對應表；(c) 皆查無 → 導向 Error Auto。
4. **主畫面 Unload 顯示**：每個 Auto 框顯示該站的 Bin、Lot、盤號（ID）與已放 IC 數（Cnt）。

### 14.5.4　互鎖與安全

> ⚠️ 注意：**分類臂放 IC 閘控**。AMR 模式下僅 normal 工作盤允許分類臂放 IC，保護 identity／cover 盤不受污染。

其他互鎖：

- **進盤確認**：須底部感測器到位（或模擬）才繼續，否則 `Feed Tray Miss` 重試。
- **推盤確認**：推盤氣缸推盤後須確認到位，未到位則退回並 `Push Tray Miss` 重試。
- **AutoY 軟體極限**：移動前先檢查軟體極限，超出彈 `Auto Y motor will out of limit` 並拒動。
- **AMR 上鎖的站**：滿車鎖定的站會被跳過，停止新出盤／餵料直到堆疊車被清空。
- **實機滿車服務**：滿車感測器 ON 時持續警告，須操作員實際清到感測器 OFF 才清資料（最後一道防線）。
- **狀態更新**：模擬／Dummy 不讀實體感測；盤臂送來的後方盤以鎖存維護，實體感測讀 OFF 不會清掉邏輯交握。
- **清機**：清機模式且全站清盤完成時不動作。

### 14.5.5　AMR/AGV 滿車交接握手（E87 SECS）

1. 滿車判定：模擬用門檻盤數，實機讀滿車感測器。
2. 鎖站：拒收新盤、出盤跳過該站。
3. 已排空（Ready）：無作業盤／後方盤／滿盤且升盤缸在原位。
4. 車已取走（Finish）：實機讀取盤端感測器為 Off＝車已被取走（模擬永遠為真）。
5. 清空堆疊車、重建堆疊角色（identity／cover／normal）、解鎖。

> SECS 連線時把滿車交給 AGV 握手，而非彈出操作員換車視窗；離線則維持原本的人工換車視窗。

### 14.5.6　操作員人工換車（僅 AMR + 一般生產 + SECS 未連線）

1. 實機滿車感測器 ON：彈 `Auto%d output stack FULL (sensor) - remove finished trays`，操作員清空堆疊到感測器 OFF 後清車資料。
2. 邏輯滿車（盤數達每車上限）：彈 `Auto%d output car full (... trays) - change car then confirm`，確認後清車資料。
3. 模擬模式：邏輯滿車時自動清空並重建堆疊，不停機。
