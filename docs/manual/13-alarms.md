# 第 13 章　警報訊息與排除

本章說明 HT160S 的警報與訊息系統：三種提示視窗（全警報 Note、OK 提示框、是/否確認框）的差異、警報如何被消除（必須先選回復鍵，純資訊提示除外）、警報發生時的蜂鳴器與三色塔燈連動行為，以及具代表性的警報訊息原因與排除方式對照表。請操作員務必先理解「絕不無聲停機」鐵則：任何使機台停止運轉的故障，一定會彈出警報。

## 13.1 警報系統概觀

HT160S 的提示介面分為兩個層級：

- **全警報視窗（標題列 `Note`）**：機台真正警報的主要提示介面。彈出時會立即停止所有馬達、機台停止運轉，並使對應機構面板紅色閃爍、發出蜂鳴，要求操作員選擇回復方式後才能繼續。
- **輕量訊息框（標題列 `Message`）**：用於一般提示與確認，分三種：僅 OK 提示、Pause 提示、是/否確認。

> ⚠️ 注意：機台所有警報與確認一律以上述全警報視窗（`Note`）或輕量訊息框（`Message`）呈現。

警報代碼目錄並非手寫固定清單，而是在開機時依本機台的氣缸／馬達／吸嘴設定動態產生，並輸出到 `system\AlarmList.csv` 供操作員查閱本機台所有可能的警報。

## 13.2 鐵則：任何使機台停止運轉的故障都會彈警報

HT160S 遵守「絕不無聲停機」鐵則：凡是會使機台運轉中停機的故障，都必須彈出警示，不得只是默默停機。背景每週期掃描馬達與安全感測器，偵測到下列任一狀況時都會停機並彈警報：

| 故障 | 觸發訊號 | 停機方式 |
| --- | --- | --- |
| Safety Door Open（安全門開啟） | 任一安全門（前／右／左／滑門右／滑門左／Auto6）開啟 | 停止所有馬達 + 彈出警報（RETRY）+ 停機 |
| Emergency Stop（急停） | 任一急停按鈕按下 | 停止所有馬達 + 鎖煞車；運轉中彈警報後停機，並要求重新回原點 |
| Motor Power Off（馬達電源關閉） | 馬達電源關閉且非上電延遲中 | 停止所有馬達 + 鎖煞車；彈警報後停機，並要求重新回原點 |
| Ion Fan Alarm（離子風扇異常） | 離子風扇異常訊號（僅實機模式，含去抖） | 減速停止所有馬達 + 彈警報 + 停機 |
| Air Pressure Low（氣壓過低） | 氣壓過低訊號 | 減速停止所有馬達 + 彈警報 + 停機 |
| 伺服軸警報（離限位） | 掃描偵測到伺服警報且非 CW/CCW 限位 | 運轉中彈出馬達警報 + 停機 |

> ⚠️ 注意：純安全感測類（急停／門／氣壓／離子風扇）若無對應警報對話框，依設計只亮紅燈、不發蜂鳴；蜂鳴只由全警報視窗觸發。
>
> ⚠️ 注意：離子風扇警報僅在實機（Real）模式生效，並具時間去抖（回原點中 20 秒、穩態 5 秒，馬達上電穩定期間略過）。

## 13.3 全警報視窗（Note）

全警報視窗為彈出式（強制式）視窗。顯示期間整機停在此視窗，主流程暫停。

### 13.3.1 控制項

| 畫面項目 | 類型 | 功能 |
| --- | --- | --- |
| 全警報視窗（標題列 `Note`） | 視窗 | 全警報彈出視窗；顯示時停止所有馬達、機台停止運轉，並對對應機構面板做紅色閃爍 |
| 警報代碼欄（Err Code，唯讀） | 顯示 | 顯示警報代碼字串（如 `SYS0001`、`SUCxxx`、馬達／氣缸動態碼） |
| 警報訊息欄（Message） | 顯示 | 顯示警報訊息文字（依語系顯示英文或中文訊息） |
| 警報明細顯示框 | 文字框 | 顯示警報細節描述與操作員動作歷程（附時間戳） |
| HOME & RETRY | 按鈕 | 回復鍵：先回原點再重試；僅當本警報提供此回復鍵時才顯示 |
| SKIP | 按鈕 | 回復鍵：跳過此料／動作 |
| RETRY | 按鈕 | 回復鍵：重試造成警報的動作 |
| TRAY FEED | 按鈕 | 回復鍵：補盤／送盤 |
| TRAY END | 按鈕 | 回復鍵：盤子結束 |
| CLEAN OUT | 按鈕 | 回復鍵：清機／清空 |
| START | 按鈕 | 恢復生產並關閉視窗；僅在已選回復鍵或本警報無回復鍵時才關閉 |
| PAUSE | 按鈕 | 停機並關閉視窗；同樣受回復鍵選擇閘控 |
| Off Buzzer | 按鈕 | 消音：使蜂鳴不再重新發聲；視窗仍開啟 |
| 機構面板群（機台俯視示意） | 顯示 | 機台俯視示意圖（各機構與料格）；警報對應的機構面板會以紅色閃爍定位 |

### 13.3.2 全警報彈出與回復流程

1. 機台動作邏輯偵測異常，依故障類型（馬達／氣缸／吸嘴／系統／卡料／Shuttle／CCD／Temp And Test 等）彈出全警報視窗。
2. 彈出時立即停止所有馬達、機台停止運轉（強制停機）。
3. 設定要提供哪些回復鍵、警報代碼、訊息、明細，並定位要閃爍的機構面板（找不到時預設為系統面板）。
4. 視窗依設定顯示／隱藏對應回復按鈕，並點亮前面板回復鍵指示燈；若未消音則立即發出警報聲。
5. 視窗持續讀取實體面板按鍵並使機構面板紅色閃爍；實體 Skip／Retry／… 鍵等同畫面觸控選取，Start／Pause 鍵等同按下對應按鈕。
6. 操作員（畫面或實體面板）選一個回復鍵。
7. 按 **START**（恢復）或 **PAUSE**（停機）；只有「已選回復鍵」或「純資訊警報（無回復鍵）」時才真正關閉視窗。
8. 關閉時關閉蜂鳴、清回復鍵指示燈、還原面板顏色；並回傳所選回復鍵給機台流程決定後續動作（Skip／Retry／Home 等）。

> ⚠️ 注意（關鍵安全規則）：若警報有提供回復鍵但操作員未選任何一個，按 START／PAUSE 都不會關閉視窗，避免未處理就帶過警報。只有純資訊提示（無回復鍵）可直接 START／PAUSE 關閉。此規則對齊 HT172／HT9045。

### 13.3.3 回復鍵對照

| 回復鍵 | 意義 |
| --- | --- |
| SKIP | 跳過此料／動作 |
| RETRY | 重試造成警報的動作 |
| TRAY FEED | 補盤／送盤 |
| TRAY END | 盤子結束 |
| CLEAN OUT | 清機／清空 |
| HOME & RETRY | 先回原點再重試 |
| （無回復鍵） | 純資訊提示，可直接關閉 |

同一警報可提供多個回復鍵，依此決定畫面顯示哪些回復按鈕。

## 13.4 輕量訊息框（Message）

輕量訊息框（標題列 `Message`）與全警報視窗不同。

| 畫面項目 | 類型 | 功能 |
| --- | --- | --- |
| Pause | 按鈕 | 一般確認 |
| Yes / No | 按鈕 | 是／否確認 |
| Off Buzzer | 按鈕 | 消音；僅警報式訊息顯示，是/否確認時隱藏 |

### 13.4.1 OK 提示流程

1. 系統彈出 OK 提示（帶入訊息字串或警報代碼）。
2. 停止所有馬達 + 機台停止運轉（停機），顯示確認（Pause）按鈕。
3. 若消音鈕可見則發出訊息提示音。
4. 操作員按 **Pause**（確認）關閉，關閉時關閉蜂鳴。

> 另有一種「不停機」OK 提示：**不停馬達、機台不停止運轉**，用於資訊／警示性質訊息。

### 13.4.2 是/否確認流程

1. 系統彈出是/否確認框（帶入訊息字串）。
2. 隱藏 **Pause** / **Off Buzzer**，顯示 **Yes** / **No** 兩鈕，預設為「否」。
3. 不停機，是/否確認不發蜂鳴（消音鈕隱藏）。
4. 操作員按 **Yes** 或 **No**，結果回傳給機台流程。

## 13.5 蜂鳴器與三色塔燈連動

警報的聲音與燈號連動分兩種驅動路徑：

- **非對話框期間**：每掃描依警報狀態階梯（全警報 → 訊息框 → 回原點 → 運轉 → 暫停）選擇蜂鳴音樣式與三色塔燈（紅／黃／綠）。
- **對話框顯示期間**：因主流程暫停，每掃描蜂鳴驅動不執行，改由視窗彈出時立即補聲（全警報視窗／訊息框各有對應提示音）。

各運轉狀態對應的蜂鳴音樣式可於維護畫面 **Tower Light** 頁的 Music Select 各狀態選項組設定。

| 參數 | 範圍/預設 | 說明 |
| --- | --- | --- |
| Music Select（Running / Error/Jam / Pause / Message / Heating / Homing 各狀態） | `0`=靜音，`1`~`4`=音樣式 1~4 | 各運轉狀態對應的蜂鳴音樣式 |
| 警報閃爍面板 | 各機構面板（如系統／進料手臂／進料 Shuttle／Temp And Test 等）；未指定時預設為系統面板 | 警報對應的機構面板，用於紅色閃爍定位 |
| 顯示語系 | `0`=英文，其他=中文 | 決定警報訊息與說明以英文或中文顯示 |
| 警報目錄輸出路徑 | `system\AlarmList.csv` | 開機產生之警報代碼目錄輸出路徑 |

### 13.5.1 消音（Off Buzzer）

按 **Off Buzzer** 會鎖存消音狀態並關閉蜂鳴。鎖存後，系統不再重新驅動蜂鳴；前面板的 **ALARM RESET** 實體鍵亦會消音。

> ⚠️ 注意：消音僅關閉蜂鳴，警報視窗仍開啟，仍需選擇回復鍵後才能 START／PAUSE 關閉。

## 13.6 警報代碼目錄與開機產生

開機時系統依本機台的氣缸／馬達／吸嘴設定動態建立整份警報目錄：

1. 清空舊的警報對照表。
2. 逐一氣缸：各產生 6 種錯誤碼（縮／伸／感測器在位等子碼），連同英中訊息與對應機構面板一併登錄。
3. 逐一馬達：各產生 9 種錯誤碼。
4. 逐一吸嘴：各產生 6 種錯誤碼。
5. 將整份警報目錄以 CSV 輸出到 `system\AlarmList.csv`（標頭 `AlarmCode,AlarmType,E_ErrMessage,C_ErrMessage,E_Description,C_Description`）。

具名系統警報以名稱查得代碼，再取雙語訊息與面板；查無時走未定義分支，以代碼首碼判斷類型並顯示 `Xxx Code Undefine Error`，代碼前加 `-` 標示。

> 註（定案，2026-07-16 查核）：現行 `system\AlarmList.csv` 共 **576 筆**（數字碼 516＋JAM 14＋MES 33＋WAR 13），中文訊息欄與中文說明欄 **仍為英文**（與英文欄逐字相同，全檔無任何中文位元組）；且無獨立處置欄，處置文字內嵌於說明欄（JAM/MES/WAR 多數為空）。中文化為待辦工作，非現場確認事項。完整清單見附錄 D；操作員排除手冊另見 `docs/alarm-troubleshooting/`。

## 13.7 代表性警報訊息與排除（對照表）

> ⚠️ 注意：下表為**代表性**清單，並非完整列舉。本機台的完整警報目錄請查閱開機產生的 `system\AlarmList.csv`（依本機氣缸／馬達／吸嘴設定動態產生）。表中代碼皆取自規格，未列舉者請勿臆測。

### 13.7.1 系統與安全類

| 警報訊息／代碼 | 原因 | 排除方式 |
| --- | --- | --- |
| `SYS%04d` / 具名系統警報 | 系統錯誤（面板：系統）；具名版以名稱查得代碼與雙語訊息 | 依警報提供的回復鍵（多為 RETRY/HOME）；查無代碼顯示 `Xxx Code Undefine Error`，需現場確認代碼來源 |
| Safety Door Open | 安全門開啟（前／右／左／滑門右／滑門左／Auto6 任一開啟） | 關閉所有安全門後按 **RETRY** 重啟 |
| Emergency Stop | 急停按下（任一急停），立即停止所有馬達 + 鎖煞車 | 釋放急停，需重新回原點 |
| Motor Power Off | 馬達電源關閉（且非上電延遲中） | 重新上電後回原點 |
| Ion Fan Alarm | 離子風扇異常（僅實機模式，含時間去抖） | 確認風扇運轉後按 **RETRY** |
| Air Pressure Low | 氣壓過低 | 恢復氣壓後按 **RETRY** |
| `COM%04d` | 系統通訊錯誤 | 依警報提供的回復鍵；附帶明細 |
| `CCD%04d` | CCD 影像／讀碼錯誤 | 依警報提供的回復鍵；附帶明細 |

### 13.7.2 機構動作類

| 警報訊息／代碼 | 原因 | 排除方式 |
| --- | --- | --- |
| `CYL%04d` / 動態氣缸碼 `4{缸序3}{子碼1}` | 氣缸動作錯誤；子碼分別代表縮／伸／感測器在位異常 | 預設回復鍵 **RETRY**；明細提示 [1] 檢查感測器 [2] 檢查線路 [3] 檢查氣壓/氣管 |
| `SUC%03d%d` / 動態吸嘴碼 `6{吸嘴序}{子碼}` | 吸嘴錯誤；子碼分別代表取料失敗／破壞／真空感測器關／元件掉落／初始感測異常 | 依警報提供的回復鍵；明細提示 [1] 檢查真空 [2] 檢查線路 [3] 檢查氣壓/氣管；重複發生時訊息加 `(Again!)` |
| 動態馬達碼 `5{馬達序}{子碼0..8}` | 馬達錯誤；子碼分別代表電源關／失步超扭／正反向極限觸發／軟體極限／位置錯誤需回原點／目標超出極限等 | 回復鍵 **RETRY**，並要求重新回原點；明細提示 [1] 檢查電源 [2] 檢查線路 [3] 檢查機構 |
| Servo alarm NOT cleared by motor power-cycle | 回原點電源循環後伺服軸仍鎖存 ALM（馬達繼電器不切斷 A6 控制電源 L1C/L2C） | 提示循環 MAIN 電源（斷路器）或排除驅動器故障後重新 HOME；停機中止避免無聲重試迴圈 |
| `JAM%04d` | 卡料錯誤（面板：系統） | 依警報提供的回復鍵（常見 SKIP/RETRY/CLEAN OUT） |
| `SHT%04d` | 進／出料 Shuttle 錯誤（進料時定位於進料 Shuttle 面板，否則出料 Shuttle 面板） | 依警報提供的回復鍵 |
| `TNT%04d` | Temp And Test 站錯誤（面板：Temp And Test） | 依警報提供的回復鍵 |
| `MAG%02d%02d` | Magazine 錯誤（相容舊機種保留） | 依警報提供的回復鍵（保留相容，現場用途需確認） |

### 13.7.3 通用與流程類

| 警報訊息／代碼 | 原因 | 排除方式 |
| --- | --- | --- |
| 通用字串警報 | 以任意字串作為代碼與訊息的通用警報（面板：系統） | 依警報提供的回復鍵（部分固定為 RETRY） |
| Loader still holds a tray | 回原點完成時 Loader 車仍持盤（夾爪已於回原點中開啟，盤已鬆脫） | 提示手動移除所有 Loader 左/右盤，按 OK 後系統清除盤身分 |
| CleanOut finish note | 清機完成提示 | 操作員選 **SKIP** 結束回 Normal 並停機 |
| Please Enter LotID ! | Start 前 LotID 為空 | 提示；輸入 LotID 後重按 Start |
| No Lot data / No 2D data / By Lot+Bin no binding | Start 前缺 Lot 註冊、缺 2D/Bin 資料、或 Lot+Bin 模式無綁定 | 提示；補齊資料／綁定後重按 Start |
| `PROCESS` | **非警報**：操作員／流程動作紀錄（START/PAUSE/SKIP/RETRY/OFF BUZZER pressed 等），寫入事件記錄並附加到警報明細 | 不適用（紀錄用途） |

> 註（定案）：Function／System Message／Record Process 三種警報型別**目前零警報掛載**——為對齊 HT172 而保留的休眠型別，唯一出現處是未定義碼的 fallback 訊息字樣（"Function/System Message/Record Process Code Undefine Error"）。「其他 (Other)」型別**有實際使用**：CCD 家族（如 `WAR16120` Top CCD connect not ready、`WAR0462`/`WAR0970` 2D no response）、種子碼（`WAR0330`、`WAR0475`、`WAR0154`）與 Auto 家族（`WAR%d30` Auto feed tray miss）。

## 13.8 互鎖與設計要點

- 彈出全警報視窗時立即停止所有馬達並使機台停止運轉，警報期間機台停止。
- 回復鍵閘控：警報若提供回復鍵，未選任何回復鍵時 START/PAUSE 皆不關閉視窗，禁止未處理就放行（對齊 HT172/HT9045）。
- 純資訊警報（無回復鍵）可直接 START/PAUSE 關閉。
- 蜂鳴只由全警報視窗觸發；純安全感測（急停／門／氣壓／離子風扇）若無警報對話框，只亮紅燈不發蜂鳴。
- Off Buzzer 為鎖存，消音後系統不再重新驅動蜂鳴。
- 對話框顯示期間主流程暫停，故每掃描蜂鳴驅動不執行，需靠視窗彈出時立即補聲；同一警報視窗已開時不重複彈出（避免重入）。

> 註（定案）：各狀態 Music Select **預設值＝[0] Mute**，實際值由 Maintenance 的號誌燈頁設定並持久化；套用時 0=全滅，1..4 對應四種蜂鳴音互斥開啟。

> 註（定案）：全警報視窗**全為英文標籤**（視窗標題 Note、回復鍵＝HOME & RETRY／SKIP／RETRY／TRAY FEED／TRAY END／CLEAN OUT／START／PAUSE／Off Buzzer）；訊息列的警報文字為執行時由警報清單填入（現行為英文，見 13.6 註）。

> 【待補（現場）：`SwMusic1..4` 各音樣式（旋律/長短）的實際聲音需現場聆聽記錄；機構面板閃爍（`FlushPanelName` 對應動態面板）正確性建議現場逐類警報抽驗一次。】
