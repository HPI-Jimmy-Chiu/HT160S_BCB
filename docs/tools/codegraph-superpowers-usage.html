3. 3 個全域技能怎麼用（移植自 Superpowers）

放在 C:\Users\jimmychiu\.claude\skills\，所有專案通用，重開後生效。都寫了「遵守該專案 CLAUDE.md 的建置/驗證規則」，不會跟 160 的 build-gate / 上機驗證 / Big5 打架。

技能何時自動出動逼我做什麼
systematic-debugging你說「當機 / hang / 壞掉 / 變慢 / 之前好好的」4 階段找根因（重現→縮小→根因→驗證），先讀 log/State Record，禁止「猜了就補 try/catch」
brainstorming要做較大/需求不清的功能前先複述目標、問關鍵問題、給 2–3 做法＋建議、列設計再動手
writing-plans多檔、跨 session 的大工程（移植、重構）切小步、每步寫清楚「怎麼驗」、存成計畫文件、逐步勾完

怎麼觸發？描述任務時自然帶出，也可明講「用 systematic-debugging 查這個 hang」。

為什麼不直接裝 Superpowers 外掛？它整套含 TDD 與 git-worktree，會在 160 強迫「沒測試就刪扣」「開多工作目錄平行改」，跟你的工控 build-gate、上機驗證、designer 存檔陷阱衝突。所以只挑 3 個安全通用的觀念移植成你的個人技能。

5. 🚀 未來在「其他專案」怎麼用（重點）

一句話：CLI 與全域技能裝一次到處有效；但 CodeGraph 的「索引」是每個專案各自一份。

5-1. 任何新專案，啟用 CodeGraph 只要 2 步

cd D:\你的新專案
codegraph init .            # 建立該專案的索引（各自獨立）

然後在該專案根目錄放一個 .mcp.json（內容跟 160 一樣）：

{
  "mcpServers": {
    "codegraph": {
      "type": "stdio",
      "command": "codegraph",
      "args": ["serve", "--mcp"]
    }
  }
}

重開 Claude Code、同意一次即可用。記得把 .codegraph/ 加進那專案的 .gitignore。

5-2. 想「一次設定、全部專案都自動有 MCP」？（建議）

不想每個專案放 .mcp.json，可把 MCP 接成全機全域。這次因 Claude Code 執行中鎖住設定檔而失敗，才改用專案層級。要全域，請在完全關閉 Claude Code 後，開一般 PowerShell 跑：

codegraph install --target claude --location global --yes

成功後，之後任何專案只要 codegraph init 就能用 MCP，不必再放 .mcp.json。

驗證：codegraph install --print-config claude 會印出它要寫進 C:\Users\jimmychiu\.claude.json 的設定。

5-3. 3 個全域技能：什麼都不用做

已在 ~/.claude/skills/，對你開的每一個專案都自動生效，不必複製、不必重裝。

6. 一頁速查

# 改程式前先看影響
codegraph impact <函式名>

# 理解一塊流程
codegraph explore "你想懂的東西，一句話"

# 找符號 / 看上下游
codegraph query <名字>
codegraph callers <名字>      # 誰呼叫它
codegraph callees <名字>      # 它呼叫誰

# 維護
codegraph status              # 看索引狀態
codegraph sync                # 手動同步
codegraph upgrade             # 升級

# 新專案啟用（2 步）
cd <專案>; codegraph init .   # + 放 .mcp.json + 加 .gitignore .codegraph/
