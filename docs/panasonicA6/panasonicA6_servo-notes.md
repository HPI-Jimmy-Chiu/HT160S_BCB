# Panasonic MINAS A6 伺服 — 開發摘要

來源手冊：`docs/panasonicA6/panasonicA6_document.pdf`（簡體中文，596 頁）。
本檔是「為了 HT160S_BCB 馬達開發」整理的重點摘要，不取代手冊；頁碼皆指該 PDF。

HT160S 這台機器的 20 軸全部走 MC88X1 軸卡（見 `ht160s-motion-card` skill），
A6 驅動器以 **脈波列位置控制模式（P 模式）** 接收 MC88X1 的命令脈波，
並把編碼器回授以 OA/OB 線驅動輸出回 MC88X1 做監看。

---

## 1. 編碼器解析度（最重要的常數）

- A6 標配 **23-bit 絕對式編碼器**：每轉 **E = 2^23 = 8,388,608 pulse/r**（P.130-131, P.310）。
- 「指令側」與「回授監看側」是兩條獨立的脈波路徑，各自有自己的「每轉脈波數」設定 —
  兩者不會自動相等，這是 Now Position / Encoder 不同步的根因（見第 4 節）。

## 2. 指令分倍頻比 / 電子齒輪（命令側 → 決定 Command/Now Position）

對應手冊 P.130「指令分倍頻比(電子齒輪比)」、P.228/233「分類0 基本設定」。

| 參數 | 名稱 | 範圍 | 出廠值 | 說明 |
|------|------|------|--------|------|
| Pr0.08* | 電機每旋轉 1 圈的「指令」脈波數 | 0–8388608 | **10000** | ≠0 時：分子自動=編碼器解析度(2^23)，分母=Pr0.08。Pr0.09/0.10 失效。 |
| Pr0.09 | 第1指令分倍頻分子 | 0–2^30 | 0 | 僅當 Pr0.08=0 時有效 |
| Pr0.10 | 指令分倍頻分母 | 1–2^30 | 10000 | 僅當 Pr0.08=0 時有效 |

`*` = 變更後需重新上電才生效。

機構關係式（丝杆螺距 L、減速比 R、編碼器 E）：
```
移動量      M  = P1 × (D/E) × (1/R) × L          ……(1)   P1=命令脈波數
位置分辨率  ΔM = (D/E) × (1/R) × L                ……(2)
電機轉速    N  = F × (D/E) × 60   (F=命令脈波頻率 pulse/s)  ……(5)
```
其中 D = 指令分倍頻比（Pr0.09/Pr0.10，或由 Pr0.08 推導）。
**白話：以 Pr0.08=10000 為例，上位送 10000 個命令脈波 = 電機轉 1 圈。**
MC88X1 的「理論/命令暫存器」(`MC88X1PGetTheorecticalRegister`) 計的就是這條命令脈波。

## 3. 脈波輸出分頻（回授側 → 決定 Encoder 顯示）

對應手冊 P.234-235「分類0」Pr0.11 / Pr5.03。

| 參數 | 名稱 | 範圍 | 出廠值 | 說明 |
|------|------|------|--------|------|
| Pr0.11* | 電機每旋轉 1 圈的「輸出」脈波數 | 1–2097152 | **2500** | OA/OB 各自每轉輸出的脈波數（線驅動回授） |
| Pr5.03* | 脈波輸出分頻分母 | 0–8388608 | 0 | =0 時直接用 Pr0.11；≠0 時輸出=(Pr0.11/Pr5.03)×E×1/4 |

關鍵公式（P.235）：
```
每旋轉一圈輸出脈波數 = (Pr0.11 / Pr5.03) × 編碼器分辨率 × 1/4   (Pr5.03≠0)
Pr5.03 = 0 時：OA/OB 每轉直接輸出 Pr0.11 個脈波
```
**MC88X1 的編碼器輸入以 ×4 四倍頻(quadrature) 計數 OA/OB**，
所以 MC88X1「實際/編碼器暫存器」(`MC88X1PGetPracticalRegister`) 每轉 = **Pr0.11 × 4**。

> 出廠對齊驗算：Pr0.08=10000（命令/轉），Pr0.11=2500 → ×4 = 10000（編碼器/轉）。
> 兩者相等 → 出廠預設下 Command 與 Encoder 本來就同步。

## 4. Command 與 Encoder 差「4 倍」的根因與對策（HT160S 實機現象）

實機現象：Motor Test 內 Now Position 與 Encoder 比值固定 ≈ 4.0（例 84.44 vs 337.59、
-151.19 vs -604.79）。兩值都先在 `myMC88X1motor.cpp` 各自乘上同一個 GearRatio，
所以 4× 不是 GearRatio 造成，而是來自命令側與回授側「每轉脈波數」不一致：

```
ratio = Encoder / Command = (Pr0.11 × 4) / (命令每轉脈波數)
```
- 出廠值 (10000 命令、2500 輸出) → ratio = 10000/10000 = 1（同步）。
- 觀測到 ratio = 4 ⇒ 代表 **Pr0.11 × 4 = 4 × 命令每轉脈波數**，
  也就是 `Pr0.11` 被設成等於命令每轉脈波數（例如兩邊都 10000），經 ×4 後編碼器讀數變 4 倍。

**對策（擇一；OA/OB 在 P 模式只供監看，迴路在驅動器內閉，改 Pr0.11 不影響定位控制）：**
1. **改 A6 `Pr0.11`**：令 `Pr0.11 × 4 = 命令每轉脈波數`，即 `Pr0.11 = 命令每轉脈波數 / 4`
   （例：命令 10000/轉 → Pr0.11 = 2500，回復出廠對齊）。變更後需重新上電。
2. 若 MC88X1 軸卡可設定編碼器計數倍率（×1/×2/×4），改為 ×1。
3. 純顯示對齊：在 `ReadMC88X1EnCoderRealPos()` 對編碼器值套用 /4 比例（最不動硬體，但治標）。

**機台確認歷程：** 初期（2026-06-17）一度誤判為「所有軸 Pr0.08=10000、Pr0.11=10000」，
並把 InitMotor 的 `SetEncodeMultiple(3)` 全改成 `SetEncodeMultiple(1)`（×1）。複查後確認：
**多數軸出廠即 Pr0.11=2500**（卡 ×4 → 2500×4=10000 剛好對齊命令），只有
**M12 `MTopCCDX`、M20 `MTopCCDX_Color`**（同機構、同驅動器設定）被設成 Pr0.11=10000，
卡 ×4 → 40000/轉 = 命令的 4 倍——這兩軸才是真正出現 4× 的軸。

**那個「×4」是 MC88X1 卡的編碼器輸入倍率**（`myMC88X1motor.cpp` InitMotor 呼叫
`SetEncodeMultiple()` = `MC88X1PSetEncoderMultiple`，見 `docs/MC88X1_Driver/MC88系列使用手冊v35.pdf`
P.53；value 0=CW/CCW、1=×1、2=×2、3=×4）。卡 ×4 配 Pr0.11=2500 本來就同步；
只有 Pr0.11=10000 的軸（M12/M20）會被卡 ×4 放大成 4 倍。

**已採用的最終修法（2026-06-22）：** 把 M12、M20 兩顆 A6 驅動器的 `Pr0.11` 由 10000 改回
**2500**（=Pr0.08/4，與其餘各軸一致），使**全機 20 軸 Pr0.11 一律 2500**。`database.cpp` 因此
統一呼叫 `SetEncodeMultiple(3)`（卡 ×4）涵蓋全部軸，移除原本 `Alias=="MTopCCDX_Color"?1:3` 的單軸特例。
2500×4 = 10000 = 命令 → 全軸 Now Position 與 Encoder 1:1 同步。編碼器(practical)暫存器在脈波列控制
下只供監看（迴路在驅動器內閉、InPos 來自驅動器訊號、軟體極限走命令計數器），改倍率不影響定位。
需 on-machine 驗證實際讀數是否已對齊。

**A6 面板改 Pr0.11 步驟：** 參數設定模式選 Pr0.11 → SET 進執行 → ▲▼/◄ 改 2500 → 長按 SET 套用 →
切 EEPROM 寫入模式 → 長按 SET 至 Finish → 斷電重開（Pr0.11 為 `*` 參數，需重新上電生效）。

另注意：`myMC88X1motor.cpp` 命令用 `if(Direction)` 取負、編碼器用 `if(Direction==0)` 取負，
兩者負號條件相反（方向不對稱 bug），與 4× 是獨立問題。HT172 用 MN200 卡，命令/編碼器
同用 `if(Direction)` 且步進馬達時編碼器=命令計數器，故 172 不會出現此現象。

## 5. 相關報警（換算/齒輪設定相關）

- **Err27.2 指令脈波倍頻異常保護**：分倍頻比過高（雜訊/抖動放大）。手冊建議分頻·倍頻比
  控制在 1/1000 ~ 1000（全閉環 1/1000 ~ 8000）倍範圍內。
- **Err25.0 混合偏差過大保護**：全閉環時指令分倍頻未固定。
- 報警代碼詳情：P.393-412。
