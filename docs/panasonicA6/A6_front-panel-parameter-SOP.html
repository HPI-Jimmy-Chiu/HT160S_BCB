Panasonic A6 驅動器 — 前面板參數設定 SOP

來源：docs/panasonicA6/panasonicA6_document.pdf，章節「14. 前面板的使用方法」（doc P.2-83～2-107 = PDF 132～156 頁）、「12. 參數和模式的設定」（doc P.2-59 = PDF 108）。
本文以 Pr0.06（指令脈衝旋轉方向） 為實例，流程適用任何 Pr 參數。
用途背景：軸卡極限脫離正規化（見 docs/MC88X1_Driver/MC88X1_technical-note.md §4 與 memory motor-test-home-and-limit-findings）。

2. 變更一個 Pr 參數的完整流程（以 Pr0.06 為例）

⚠ 一次只調一顆軸；改完務必 EEPROM 寫入 + 斷電重開 才生效（Pr0.06 屬「r」類，需重新上電）。

A. 進入參數設定模式

  1. 上電、等監視器畫面出現。
  2. 按 M，直到顯示變成參數編號（形如 Pr 0.00）= 參數設定「選擇狀態」。多按過頭就繼續按 M 轉一圈回來。

B. 選到 Pr0.06

  1. 用 ◀ 移動閃爍位數、用 ▲/▼ 改數字，調到 Pr 0.06。（Pr 後第一位=類別 0，小數點後兩位=編號 06）

C. 顯示並變更數值

  1. 按 S → 進入「執行狀態」，顯示目前數值（最右小數點閃爍 = 編輯位）。
  2. 用 ▲/▼ 改值。Pr0.06 只有 0/1，按一下即切到另一值。多位數參數可用 ◀ 換位。
  3. 按 S → 回「選擇狀態」（又顯示 Pr 0.06）。此時只改在 RAM，尚未存檔。

D. 寫入 EEPROM（必做）

  1. 按 M，直到顯示 EE_SEt = EEPROM 寫入模式。
  2. 按 S → 執行狀態，顯示 EEP -。
  3. 長按 ▲ → 右側橫線增加：EEP - → EEP -- → EEP --- → … → StArt（開始）→ FiniSh（完成）。
    • 顯示 reSet：此參數需重啟才生效（Pr0.06 屬此）。  • 顯示 Error：寫入失敗，重做；Err11.0=控制電源不足則無法寫入。

E. 斷電重開 + 確認

  1. 切斷控制電源，重新上電。
  2. 重開後回參數設定模式調到 Pr 0.06、按 S 看值，確認已是新值。

3. 搭配軸卡正規化（A 路線）每軸要做的事

對每顆 Direction=1 的軸（M01–M04、M06–M11、M14–M17、M19、M20）：

  1. 驅動器：本文流程翻轉 Pr0.06（0↔1）+ EEPROM 寫入 + 斷電重開。
  2. system/Mot_Table.csv：該軸 Direction 1→0（執行期讀取，不必重編，重啟程式生效）。
  3. Mot_Table.csv：該軸 HomeDirectior 暫時翻一下，由 home 驗證決定對錯。
  4. 五項驗證：Jog 方向不變 / 極限燈對位（右=CW、左=CCW）/ 原生脫離可用 / NowPosition 與 Encoder 同向且貼近 / Home 正常。
兩個（Pr0.06 + Direction）一定要成對翻：只翻一個會讓實體動作反向，翻兩個才是淨中性（Jog/MoveTo/教導點位置不變），目的只是讓脈波方向對齊極限接線，卡片就原生允許脫離。
排錯（M19 rollout 教訓）：若翻 Pr0.06 後 Jog 方向「看似沒變」，先別當成硬體手性/接線問題——多半是設定沒真的生效。依序確認：(1) Pr0.06 EEPROM 寫入後斷電重開並讀回確認值真的存進去；(2) Pr0.07(指令脈衝輸入模式) 與軸卡輸出模式一致（本機 1P2P=1 → 軸卡 mode 4 CW/CCW 雙脈波，Pr0.07 要對應）；(3) 同型軸彼此比對方向相關欄位（如 M19 vs M20）。M20 方法本身正確，M19 卡關是設定沒對上，不是方法錯。先查這三點再考慮硬體。
