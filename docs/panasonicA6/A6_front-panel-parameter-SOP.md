## 1. 前面板按鍵（手冊 P.2-83）

6 位數 7 段 LED 顯示 + 5 顆按鍵：

| 鍵 | 名稱 | 功能 |
|----|------|------|
| **M** | 模式切換鍵 (MODE) | 在 4 種模式間循環：①監視器 → ②參數設定 → ③EEPROM 寫入 → ④輔助功能 →（回①）|
| **S** | 設置鍵 (SET) | 在「選擇狀態」與「執行狀態」間切換 / 確認 |
| **◀** | 移位鍵 | 把要變更的位數往左移（選位） |
| **▲** | — | 數值增加 |
| **▼** | — | 數值減少 |

**上電顯示順序**（手冊 P.2-84）：約 2 秒全亮 → `......` → `888888` → 監視器初始畫面
（如 `r　　　0`，由 Pr5.28 決定）。出現監視器畫面即可開始操作。

**模式循環（按 M）：**
```
監視器模式  --M-->  參數設定模式  --M-->  EEPROM寫入模式  --M-->  輔助功能模式  --M-->  (回監視器)
 d00uEP            Pr 0.00            EE_SEt              AF_AcL...
```

## 2. 變更一個 Pr 參數的完整流程（以 Pr0.06 為例）

> ⚠ 一次只調一顆軸的驅動器；Servo 不必 On 也能改參數，但改完 **務必 EEPROM 寫入 + 斷電重開** 才生效（Pr0.06 屬「r」類，需重新上電）。

### A. 進入參數設定模式
1. 上電、等監視器畫面出現。
2. 按 **M**，直到顯示變成參數編號（形如 **`Pr 0.00`**）= 參數設定模式的「選擇狀態」。
   （若多按過頭，繼續按 M 轉一圈回來即可。）

### B. 選到 Pr0.06
3. 用 **◀** 移動閃爍位數、用 **▲/▼** 改數字，把顯示調到 **`Pr 0.06`**。
   - `Pr` 後第一位 = 類別 (class 0)，小數點後兩位 = 編號 (06)。

### C. 顯示並變更數值
4. 按 **S** → 進入「執行狀態」，顯示**目前數值**（最右側小數點會閃爍 = 正在編輯位）。
5. 用 **▲/▼** 改值。Pr0.06 只有 `0` / `1`，按一下 ▲ 或 ▼ 即在 0↔1 之間切換到**另一值**。
   - 多位數參數可用 **◀** 換位再 ▲/▼。
6. 按 **S** → 回到「選擇狀態」（又顯示 `Pr 0.06`）。**此時只改在 RAM，尚未存檔。**

### D. 寫入 EEPROM（必做）
7. 按 **M**，直到顯示 **`EE_SEt`** = EEPROM 寫入模式。
8. 按 **S** → 執行狀態，顯示 **`EEP -`**。
9. **長按 ▲** → 右側橫線逐漸增加：`EEP -` → `EEP --` → `EEP ---` → … → 顯示 **`StArt`**（開始寫入）
   → **`FiniSh`**（完成）。
   - 若顯示 **`reSet`**：此參數需重啟才生效（Pr0.06 就是這類）。
   - 若顯示 **`Error`**：寫入失敗，重做；若 Err11.0（控制電源不足）則無法寫入。

### E. 斷電重開 + 確認
10. **切斷控制電源，重新上電。**
11. 重開後回參數設定模式調到 `Pr 0.06`、按 S 看值，確認已是新值。

## 3. 搭配軸卡正規化（A 路線）每軸要做的事

對每顆 **Direction=1** 的軸（M01–M04、M06–M11、M14–M17、M19、M20）：

1. 驅動器：本文流程翻轉 **Pr0.06**（0↔1）+ EEPROM 寫入 + 斷電重開。
2. `system/Mot_Table.csv`：該軸 **`Direction` 1→0**（執行期讀取，不必重編，重啟程式生效）。
3. `Mot_Table.csv`：該軸 **`HomeDirectior`** 暫時翻一下，由 home 驗證決定對錯。
4. 五項驗證：Jog 方向不變 / 極限燈對位（右=CW、左=CCW）/ 原生脫離可用 / NowPosition 與 Encoder 同向且貼近 / Home 正常。

> 兩個（Pr0.06 + Direction）一定要**成對翻**：只翻一個會讓實體動作反向，翻兩個才是淨中性
> （Jog/MoveTo/教導點位置不變），目的只是讓脈波方向對齊極限接線，卡片就原生允許脫離。

> **排錯（M19 rollout 教訓）：若翻 Pr0.06 後 Jog 方向「看似沒變」，先別急著當成硬體手性/接線問題——
> 多半是設定沒真的生效。依序確認：(1) Pr0.06 EEPROM 寫入後**斷電重開**，並**讀回**確認值真的存進去；
> (2) `Pr0.07`(指令脈衝輸入模式) 與軸卡輸出模式一致——本機 `1P2P=1` → 軸卡走 mode 4（CW/CCW 雙脈波），
> Pr0.07 要對應；(3) 同型軸彼此比對（如 M19 vs M20）方向相關欄位是否一致。M20 方法本身是對的，
> M19 當初卡關是設定沒對上，不是方法錯。**先把上面三點查清楚，再考慮硬體。**
