本版本（V1.0.0.4）針對貴司 2026-09-16 提出之「**清機（Clean Out）排空未完成前不得補料**」防呆需求交付。

## 【問題現象】

清機排空尚未結束時，若操作員把新的料盤放上上料車，清機流程會一直停在未完成，機台卻繼續生產。系統紀錄（EventLog）會留下一筆記錄，但畫面上沒有任何提示，因此現場不易察覺。

若按下清機時車上原本就還有料，屬正常情形，不在此列。

## 【原因】

機台判斷「該側可以退出生產」的條件之一是上料來源已經沒有料。排空途中補料會讓這個條件重新變成不成立，該側便重新加入生產排程，清機的完成條件因此永遠無法達成。

## 【本版修正】

1. 本次清機期間，若上料來源曾被判定為沒有料，之後又**持續 1.5 秒**偵測到有料，機台判定為「排空中補料」。
2. 判定成立時發出 **MES0927 停機**，畫面提示
   `Clean Out still running - remove the new trays and let the drain finish`
   請操作員將新放的料盤取回後再繼續。
3. 採用「**由無到有的變化**」判定，而非單純看有無料，因此按下清機時車上仍有料的正常作業**不受影響**。

## 【操作上的影響】

- 安裝後操作方式不變，**不需任何手動處理或重新設定**。
- 此防呆**預設開啟**。若貴司需要關閉或調整確認時間，請告知，我方可協助設定（參數位於機台設定檔 `[Safety]` 區段）。
- 此防呆**僅在未使用 AMR 的模式下生效**。使用 AMR 時，補料屬於搬運車的正常作業，不視為異常。

## 【同版一併交付的其他改善】

本版另含下列改善，安裝後即生效，**操作方式均不變**：

| 項目 | 內容 |
|---|---|
| 出料盤紀錄 | 清機排空時，盤離開夾持的時點即完成帳務登錄，避免中途中斷造成機台誤認車上仍有盤。連帶影響：出料盤事件與盤數的回報時點提前約數百毫秒。 |
| 上料夾持 | 修正供料後不必要的鬆夾動作。 |
| 批次操作 | Lot Start / Lot End 兩顆按鈕改為互斥，避免誤操作。 |
| 帳號與權限 | 登入畫面可達性與稽核紀錄改善；新增自動登出；權限判定失敗時降為最低權限。Map Tray 頁面改為設備商專用。 |

> 另有一項「托盤夾持感測判定」的新功能已隨本版交付，但**預設為關閉**，需待機構調整完成後才會啟用；在啟用前對機台行為完全沒有影響。
